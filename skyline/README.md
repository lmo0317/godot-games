# skyline (가칭: 도트 미니 시티)

시티즈 스카이라인을 아주 단순하게 줄인 도트 스타일 도시 건설 게임입니다. 첫 플레이 버전(MVP)이 있습니다.

- 플레이: https://minohlee.mooo.com/mini-city/ (집 안에서는 http://192.168.219.112/mini-city/)
- 방향: [게임 방향성](docs/GAME_DIRECTION.md)
- 작업 기록과 다음 할 일: [TASKS](docs/TASKS.md)

방향 요약:
- 카이로소프트처럼 귀엽고 가벼운 도트 그림, 시티즈 스카이라인처럼 도로와 구역을 칠하면 도시가 스스로 자람
- 걸어 다니는 주민과 돈 팝업, 마을 랭크로 해금과 땅 확장
- 한 판 10년, 끝나면 도시 점수. 땅과 이벤트가 무작위라 맵을 손으로 만들지 않음

이름·로고·그림에 "Cities: Skylines"를 쓰지 않습니다(장르 구조만 참고).

## 첫 버전에 들어간 것

| 항목 | 내용 |
|---|---|
| 맵 | 32×32 무작위(강·해안·호수, 숲). 시작 16×16, 랭크마다 넓어짐 |
| 건설 | '건설' 상점: 도로(물 위는 다리), 주거·상업·공업 구역, 철거, 시설 9종, 명소 3종. 실행 취소(같은 달) |
| 성장 | 도로 2칸 안 + 전기 + 물이면 건물이 지어지고 지가에 따라 1→3단계로 자람 |
| 수요 | 주거·상업·공업 막대. 세금 3단계 |
| 랭크 | 마을 → 읍 → 소도시 → 도시 → 대도시 |
| 이벤트 | 8종(축제, 호황·불황, 화재 등). 연말 결산과 정책 카드 3장 중 1장 |
| 끝 | 10년 뒤 도시 점수, 최고 기록. 오늘의 도시(날짜로 같은 땅) |
| 저장 | 매달 자동 저장, 타이틀에서 이어하기 |

조작(가로 화면, 클래시 오브 클랜과 같게 — [조사](docs/CLASH_PLACEMENT.md)):
- 한 손가락으로 끌면 언제나 맵 이동, 두 손가락(또는 휠)으로 확대
- 오른쪽 아래 '건설'에서 고르면 화면 가운데에서 가장 가까운 빈 칸에 미리보기가 나옴(도로·구역은 도로 옆 우선)
  - 미리보기를 끌면 옮겨지고, ✓로 짓고 ✕로 취소. 다른 칸을 눌러도 미리보기는 그대로
  - 시설·구역·철거는 지으면 바로 기본 상태로
- 도로는 성벽처럼: ✓를 누르면 한 칸 지어지고 같은 방향으로 다음 칸이 자동으로 나옴. 초록 화살표를 끌면 길게 그어서 한 번에 지음. ✕로 끝냄
- 구역·철거: 한 칸으로 시작, 화살표를 끌면 네모로 넓어짐, 안쪽을 끌면 옮겨짐
- 칸을 누르면 아래에 [정보] [철거]. 시설은 화살표가 나오고, 끌면 다른 칸으로 옮겨짐(손을 떼면 저장, 못 놓는 곳이면 제자리로)
- 미리보기를 화면 가장자리로 끌면 맵이 따라 움직임

## 폴더

| 경로 | 내용 |
|---|---|
| `scripts/city.gd` | 시뮬레이션 전부(맵, 성장, 수요, 지가, 돈, 이벤트, 저장). 노드 없이 돌아감 |
| `scripts/defs.gd` | 숫자·목록 데이터(시설, 랭크, 이벤트, 정책) |
| `scripts/main.gd` | 화면: 타이틀, 카메라, 입력, 위·아래 막대, 팝업 |
| `scripts/map_view.gd`, `walkers.gd`, `fx_layer.gd` | 맵 그리기, 주민·차, 돈 효과 |
| `tests/test_sim.tscn` | 규칙 검사 + 봇(`city_bot.gd`)이 6판을 10년씩 두고 밸런스 표를 출력 |
| `tools/` | 도트 그림(`generate_sprites.py`), 효과음(`generate_sfx.py`), 글꼴 줄이기, 웹 빌드·112 배포 |
| `art/` | Gemini 콘셉트 그림(게임에는 타이틀 그림으로만 사용) |

## 명령

```bash
python tools/generate_sprites.py
python tools/generate_sfx.py
bash tools/build_web.sh
python tools/deploy_112.py
```

테스트: `Godot --headless --path . res://tests/test_sim.tscn`
