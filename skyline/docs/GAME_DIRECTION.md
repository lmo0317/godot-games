# 게임 방향성 — 도트 미니 시티 (가칭)

2026-10-02 작성. [시티즈 스카이라인 분석](CITIES_SKYLINES_ANALYSIS.md)과 [카이로소프트 분석](KAIROSOFT_ANALYSIS.md)을 바탕으로, 우리가 만들 게임의 방향을 정합니다. 세부 수치와 목록은 다음 단계의 기획서에서 확정합니다.

## 1. 한 줄 정의

> **카이로소프트처럼 귀엽고 가볍게, 시티즈 스카이라인처럼 "구역을 칠하면 도시가 스스로 자라는" 도트 도시 건설 게임.**
> 한 판은 정해진 기간(예: 10년)이고, 끝나면 도시 점수로 토스 랭킹에서 겨룹니다.

## 2. 왜 이 조합인가

| | 시티즈 스카이라인에서 | 카이로소프트에서 |
|---|---|---|
| 가져오는 재미 | 구역만 칠하면 건물이 지어지고 자람, 수요 막대, 서비스 범위, 지가, 인구 단계와 땅 확장 | 귀여운 도트, 걸어 다니는 주민, 돈 팝업, 콤보와 도감, 숫자로 명확한 랭크, 정해진 기간 후 점수·랭킹, 이어받기 |
| 버리는 것 | 교통 시뮬레이션, 배관·전선망, 복잡한 세금·예산·대출, 지구·정책, 끝없는 샌드박스 | 스태미나·대기시간·광고 룰렛 같은 플레이를 막는 과금 |

**우리만의 위치:** 모바일에서 "구역을 칠하는" 진짜 도시 건설을 짧은 판과 랭킹으로 즐기는 게임은 드뭅니다. SimCity BuildIt은 타이머·과금형이고, Pocket City는 샌드박스형입니다.

## 3. 디자인 기둥 다섯 가지

1. **칠하면 자란다:** 플레이어는 도로와 구역만 정합니다. 건물은 수요와 지가에 따라 저절로 지어지고 1→2→3단계로 자랍니다.
2. **보는 재미:**
   - 도트 주민이 집 → 일터·가게 → 집으로 걸어 다닙니다.
   - 가게에 들어가면 머리 위로 동전이 튀고, 차는 도로 위를 장식처럼 지나갑니다.
   - **돈이 들어오는 순간이 화면에 보여야 합니다.** Venture Towns가 비판받은 지점입니다.
3. **조합을 발견한다:**
   - 특정 건물 3개를 3칸 안에 두면 콤보가 됩니다. 예: 빵집 + 카페 + 공원 = "브런치 거리".
   - 지가와 수입이 오르고, 콤보 도감이 채워집니다. 이것이 핵심 수집 재미입니다.
4. **짧고 명확한 목표:**
   - 마을 랭크(마을 → 읍 → 소도시 → 도시 → 대도시)의 조건을 숫자로 보여 줍니다. 예: 인구 300, 콤보 5개.
   - 랭크가 오르면 건물이 열리고 땅이 넓어집니다.
5. **매 판 다르게, 끝은 점수로:**
   - 땅(강·숲·언덕·해안)과 이벤트가 무작위라 매 판 다릅니다. **맵을 손으로 만들지 않습니다.**
   - 10년이 끝나면 도시 점수를 매겨 랭킹에 올립니다. 오늘의 도시(날짜 시드, 모두 같은 땅)로도 겨룹니다.

## 4. 핵심 순환

```
도로를 깐다 → 구역(주거·상업·공업)을 칠한다 → 주민이 이사 오고 건물이 자란다
   ↑                                                     ↓
땅 확장·새 건물 해금 ← 마을 랭크 상승 ← 수입·인구·콤보 ← 공공시설·공원으로 지가를 올린다
```

- **한 판:** 10년, 1년은 실제 2~3분입니다. 한 판에 25~30분이고 빨리 감기가 있습니다. 중간 저장해서 이어 할 수 있습니다.
- **연말:** 신문 헤드라인으로 올해 성과를 알리고, 시상과 보너스를 줍니다.
- **판이 끝나면:** 도시 점수 → 랭킹. 콤보 도감과 발견한 건물은 다음 판에 이어받습니다.

## 5. 시스템 초안 (원작과 비교)

| 시스템 | 원작(시티즈 스카이라인) | 우리 게임 |
|---|---|---|
| 구역 | 7종, 레벨 1~5 | **주거·상업·공업 3종, 1~3단계** |
| 수요 | RCI 막대 | 막대 3개 그대로. 가장 필요한 구역이 반짝임 |
| 도로 | 종류 다양, 교통 시뮬레이션 | **1~2종, 연결만 판정**. 차는 장식 |
| 기반시설 | 전기·상수·하수 배관망 | **발전소·급수탑의 범위**. 범위 밖 건물은 자라지 않음 |
| 공공 서비스 | 경찰·소방·의료·교육·쓰레기·장례 | **3~4종**(치안·소방·병원·학교), 범위형 |
| 지가 | 서비스, 공원, 물가 +, 오염·소음 − | 같은 원리를 칸 단위로 단순화. 공업 주변은 −, 공원·물가는 + |
| 콤보 | 없음 | **카이로소프트식 3개·3칸 콤보 + 도감** |
| 세금·예산 | 구역별 세율 1~29%, 예산 슬라이더, 대출 | **세율 3단계(낮음·보통·높음)**, 대출 없음 또는 1종 |
| 단계·해금 | 인구 마일스톤, 땅 타일 구매 | **마을 랭크 5단계**, 랭크마다 건물 해금과 땅 확장 |
| 특별 건물 | 유니크 빌딩, 모뉴먼트 | **명소 몇 개**(조건 달성 시). 점수 보너스 |
| 사건 | 재난 DLC | **무작위 이벤트**: 축제, 관광객 붐, 화재, 경기 호황·불황 |
| 끝 | 없음 | **10년 후 도시 점수 → 랭킹**, 이후 계속 가능(점수 고정) |

## 6. 그림·화면

- **도트:** 16×16 칸을 3배로 키워 48px. 위에서 내려다본 시점(살짝 기운 정면)입니다.
  - 쿼터뷰(아이소메트릭)보다 그리기와 터치 판정이 쉽습니다.
- **그리는 방법**
  - 건물, 길, 땅 타일, 주민은 **코드로 그립니다**(Pillow 스크립트). 팔레트를 정해 통일감을 냅니다.
  - Gemini는 투명 배경 스프라이트를 정확히 못 그리므로 타이틀 일러스트나 스토어 이미지에만 씁니다.
  - 무료 CC0 도트 타일 팩을 받아 쓰는 방법도 있습니다(다운로드 허락 필요).
- **화면:** 가로 1280×720입니다(2026-10-04에 세로에서 바꿈). 짓기는 클래시 오브 클랜처럼 합니다.
  - 왼쪽 위: 랭크와 다음 랭크 조건. 가운데 위: 날짜와 월 수지. 오른쪽 위: 돈·인구·행복·수요
  - 왼쪽: 메뉴, 속도, 실행 취소. 아래: 비서 메시지 줄. 오른쪽 아래: '건설' 버튼
  - '건설' → 상점 창(도로·구역 / 시설 / 명소 탭) → 카드를 누르면 맵에 미리보기가 나옴
  - 미리보기 위의 ✕/✓로 취소·확정. 미리보기를 끌면 옮기고, 빈 땅을 끌면 맵이 움직임
  - 토스에 낼 때는 오른쪽 위(닫기 버튼 자리)와 돈 표시가 겹치는지 확인해야 합니다.

## 7. 랭킹과 플랫폼

- **점수:** 인구, 자금, 평균 지가, 콤보 수, 명소, 행복도를 합칩니다. 공식은 기획서에서 정합니다.
- **랭킹:** 토스 리더보드(앱당 1개)에는 10년 점수를 올립니다. 오늘의 도시는 우리 서버 랭킹을 HTTPS(`minohlee.mooo.com`)로 쓸 수 있는지 검토합니다.
- **수익:** 토스 보상형 광고는 **편의 기능에만** 씁니다(예: 빨리 감기 연장, 이벤트 즉시 열기). 점수에 영향을 주는 결제는 넣지 않습니다(랭킹 공정성).
- **출시 경로:** 퍼즐블록과 같습니다. 원스토어로 등급을 받고 앱인토스에 출시하며, 웹은 112 서버에 둡니다.

## 8. 첫 버전 범위 (MVP)

| 항목 | 첫 버전 |
|---|---|
| 맵 | 무작위 생성, 시작 16×16 → 최대 32×32 |
| 구역 | 주거·상업·공업 × 3단계 |
| 시설 | 기반 2종, 공공 4종, 공원·장식 4종, 명소 3종 |
| 콤보 | 12종 + 도감 |
| 랭크 | 5단계 |
| 이벤트 | 8종 |
| 주민 | 최대 수십 명이 화면에서 돌아다님. 숫자상 인구는 더 클 수 있음 |
| 한 판 | 10년 (25~30분), 빨리 감기, 중간 저장 |
| 모드 | 일반 + 오늘의 도시 |

**예상 기간:** 퍼즐블록의 3~4배입니다. 첫 플레이 가능 버전까지 2~3주, 출시 품질까지 1~2개월로 봅니다.

## 9. 위험 요소와 대응

| 위험 | 대응 |
|---|---|
| 밸런스(돈·성장 곡선) | 퍼즐블록처럼 **봇이 수백 판을 자동으로 두게 해서** 측정하고 맞춤 |
| 도트 그림 작업량 | 건물 수를 작게 시작. 코드 생성과 팔레트 규칙으로 통일 |
| 웹·폰 성능 | 교통 시뮬레이션 없음, 화면에 보이는 주민 수 제한 |
| 폰에서 건설 조작 | 끌어서 도로·구역 칠하기, 실행 취소, 확대·이동. 첫 버전부터 실제 폰으로 확인 |
| 한 판이 길어 토스 사용자와 안 맞음 | 중간 저장, 빨리 감기. 필요하면 5년짜리 짧은 모드 |
| "혼자 굴러가는" 지루함 | 매년 고를 일(정책 카드, 이벤트 선택)과 랭크 조건으로 계속 할 일을 줌 |
| 지적재산권 | "Cities: Skylines", "카이로소프트" 이름·그림·고유 콘텐츠를 쓰지 않음. 장르 구조만 참고 |

## 10. 정해야 할 것

1. **시점:** 위에서 내려다보기(추천) vs 쿼터뷰
2. **한 판 길이:** 10년 25~30분(추천) vs 더 짧게
3. **게임 이름:** "도트 미니 시티"는 가칭입니다.
4. **교통 표현:** 장식용 차만(추천) vs 아주 단순한 혼잡도(도로 색만 바뀜)
5. **도트 그림:** 코드로 직접 그리기(추천) vs 무료 CC0 타일 팩 사용
