# 아트 가이드 — 도트 미니 시티

아트 디렉터 스킬(`art-director`)이 그림을 만들기 전에 읽는 기준입니다. 바뀌면 여기부터 고칩니다.

## 스타일 한 줄

**손으로 칠한 만화풍 기지 건설 게임(클래시 오브 클랜 풍).** 2:1 쿼터뷰 위에서 내려다보는 시점, 통통하고 둥근 형태, 밝고 진한 색, 왼쪽 위에서 오는 따뜻한 빛과 차가운 그림자, 얇은 어두운 외곽선. 장난감처럼 작게 보여도 또렷해야 합니다.

2026-10-06에 화풍을 통째로 바꿨습니다(사용자 요청 "아트 스타일 풍 다 바꿔"). 시안 A(3D 렌더 느낌)와 B(손으로 칠한 느낌) 중 **B**를 골랐습니다.

바뀐 순서:
1. 16px 코드 도트
2. Codex 정면 일러스트풍("구림")
3. 키 큰 쿼터뷰("가려서 못 씀")
4. 카이로 풍 낮은 쿼터뷰 도트
5. **클래시 풍 칠한 그림(지금)**

남의 게임 그림·UI는 베끼지 않습니다(느낌만 참고하고 그림은 전부 새로 만듦). 프롬프트에도 게임 이름을 쓰지 않습니다.

## 크기와 시점

- **맵 칸:** 64×32 마름모. 셀 (x, y)의 중심 = ((x − y)·32, (x + y)·16)
- **해상도:** 그림은 2배 해상도로 저장하고 절반 크기로 그립니다(`MapView.DETAIL`). 항상 부드럽게 축소·확대합니다(LINEAR + mipmap).
- **크기:**

| 종류 | 저장 크기 |
|---|---|
| 땅 타일 | 128×64 |
| 건물·시설 | 가로 104px(돌 받침·작은 화분 포함) |
| 주민 | 세로 34px |
| 차 | 가로 46px |
| 아이콘 | 가로 54px |
| 말풍선 | 34px |
| 동전 | 26px |
| 비서 얼굴 | 세로 76px |

## 규칙

- **그림 바탕:** 투명 배경, 땅·그림자·글자·로고 없음. 간판은 글자 대신 그림
- **받침:** 건물은 자기 칸 위 돌 받침에 서 있습니다(시트에서 같이 그려짐)
- **물은 섬 밖에만:** 지도 전체가 섬이고, 바다는 섬 둘레에 그립니다(모래 해변·물거품·앞쪽 바위 절벽). 고속도로는 바다 위 다리로 들어옵니다. 섬 안에는 강·호수를 만들지 않습니다(배치가 불편하다는 사용자 요청, 2026-10-07)
- **구별:** 주거·상업·공업 건물과 빈 땅(울타리 잔디·돌 포장·노란 줄 콘크리트)을 한눈에 구별할 수 있어야 합니다
- **글자:** UI 글자는 흰색에 두꺼운 어두운 외곽선(클래시식). 밝은 비서 상자 안 글자만 어두운 색
- **차분함:** 게임 안 그림은 차분하게. 큰 일러스트는 타이틀 액자 안에만 씁니다

## 만드는 방법

| 종류 | 방법 | 위치 |
|---|---|---|
| 건물·시설·명소·공사장·나무·주민·차·아이콘·말풍선·비서 | **Codex 시트**: 6개씩 한 장에 그리기(기준 그림 첨부) → `tools/sheet_cut.py`로 잘라 부드럽게 축소. 목록·프롬프트는 `tools/paint_art.py`의 `SHEETS` | 시트 원본 `art/raw/sheets/`(git 제외), 게임용 `assets/sprites/px/` |
| 잔디(풀결·작은 꽃)·바다(해변 16종×2프레임)·돌 포장 도로 16종·다리·빈 구역·차 색 4가지·앱 아이콘 | 코드(`tools/generate_ground.py`, 4배로 계산 후 축소). 바다 둘레·절벽은 `MapView._draw_sea`, `_draw_map_edge` | `assets/sprites/px/` |
| 버튼·창·상태 막대·비서 말 상자 | 코드(`tools/generate_ui.py`) → `UIKit`가 나인패치로 씀(모서리 24px) | `assets/ui/` |
| 불꽃 | 옛 코드 도트 | `tools/generate_sprites.py` → atlas |
| 타이틀 일러스트 | Codex | `assets/art/title.jpg` |

- **기준 그림:** `art/style_ref_painted.png`(처음 통과한 시험 시트: 주택·빵집·공장·발전소·급수탑·경찰서). Codex로 생성할 때마다 붙입니다.
- **새 그림을 만들 때:**
  1. `SHEETS`에 시트 한 줄을 추가합니다. 같은 묶음은 한 장에, 한 줄로, 같은 축척으로 그립니다.
  2. `python tools/paint_art.py --gen <시트>` 를 실행합니다.
  3. 검수 시트를 만들어 확인합니다.
- **자르기만 다시:** `python tools/paint_art.py --fit all`
