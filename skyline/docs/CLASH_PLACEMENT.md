# 클래시 오브 클랜 배치 방식 조사

2026-10-04 조사. "클래시처럼 배치되게"를 제대로 맞추기 위해 클래시의 배치 방식을 단계별로 확인했습니다.

**출처의 한계:**
- 위키(Fandom)의 업데이트 기록, Supercell 옛 포럼(archive.org), 튜토리얼로 확인했습니다. Reddit은 열리지 않았습니다.
- 손동작의 세부(버튼 위치 등)는 글로 남은 자료가 거의 없습니다. 이런 내용은 **(미확인)** 으로 표시했습니다. 플레이 영상에서 흔히 보이는 동작이지만, 실제 기기에서 한 번 확인하면 좋습니다.

## 1. 상점에서 새 건물 사기

- **상점과 등장 위치:** 상점에서 건물을 누르면 상점이 바로 닫히고, 맵에 건물이 "들린 채" 나타납니다.
- **(미확인) 나타나는 자리:** 지금 보이는 화면 가운데에서 가장 가까운 **빈 자리**에 나타납니다. 카메라는 다른 곳으로 날아가지 않습니다.
- **아직 안 놓은 건물:** 화면 아래 가운데에 아이콘으로 계속 남습니다.

## 2. 미리보기(배치 중인 건물)

- **(미확인) 모양:**
  - 건물은 거의 그대로 보입니다.
  - 바닥 칸은 놓을 수 있으면 **초록**, 없으면 **빨강**입니다.
  - 마름모 네 변 바깥에 화살표 4개가 있습니다. 화살표는 "끌 수 있다"는 표시일 뿐 버튼이 아닙니다.
- **(미확인) ✓/✗ 버튼:** 건물 바로 위에 붙어서 건물과 같이 움직입니다.
- **방어 건물:** 놓는 동안 공격 범위 원이 보입니다.

## 3. 미리보기 옮기기

- **건물 끌기:** 건물 자체를 끌면 칸 단위로 따라옵니다. 처음 잡은 위치의 차이를 유지해서, 건물이 손가락 밑으로 튀지 않습니다.
- **빨간 곳:** 끄는 동안 빨간 곳 위도 지나갈 수 있습니다.
- **(미확인) 빈 땅을 끌면** 맵이 움직입니다. 미리보기는 그 자리에 남습니다.
- **(미확인) 다른 칸을 눌러도 건물이 그리로 가지 않습니다.** 포럼에 "누른 곳에 놓게 해 달라"는 요청이 있었던 것도 원래는 안 된다는 뜻입니다.
- **(미확인) 빨간 곳에서는** ✓가 회색이 되어 눌리지 않습니다. 팝업 같은 다른 안내는 없습니다.

## 4. 확정한 뒤

- **보통 건물:** ✓를 누르면 공사가 시작되고 곧바로 기본 상태로 돌아갑니다.
- **(미확인, 전통적인 동작) 성벽:**
  - ✓를 누르면 **바로 옆에 다음 성벽 미리보기가 자동으로** 나옵니다. 방향은 이전 성벽에서 이어지는 쪽입니다.
  - 그래서 직선으로 쌓을 때는 **한 칸에 ✓ 한 번**이면 됩니다.
  - 꺾을 때는 미리보기를 한 번 끌어 옮기고, 그다음부터는 새 방향으로 이어집니다.
  - ✗를 누르거나 돈·성벽이 떨어지면 끝납니다.
- **업데이트로 생긴 것:**
  - 2013: 성벽 한 줄 옮기기, 한 줄 회전
  - 2013: 편집 모드에서 성벽 화살표를 끌어 길게 긋기
  - 2014: "줄 선택"(Select Row)
  - 2025: 일반 화면에서도 성벽을 끌어 긋기(일부 확인)

## 5. 이미 지은 건물 옮기기

- **먼저 눌러서 선택:**
  - 건물이 반짝이고 화살표 4개가 나옵니다.
  - **화면 아래에 정보·업그레이드 등 버튼 줄**이 나옵니다.
- **선택한 뒤에 끌면 옮겨집니다.** 선택하지 않은 건물을 끌면 맵이 움직입니다. 길게 누르기는 없습니다(헤이데이는 길게 누르기).
- **확인 버튼 없이** 손을 떼는 순간 저장됩니다. (미확인) 빨간 곳에 놓으면 원래 자리로 돌아갑니다.
- **가장 큰 불만은 "실수로 옮겨짐"입니다.**
  - "맵을 움직이다 건물이 옮겨진다"는 불만이 많았습니다.
  - Supercell은 잠금 기능을 끝내 넣지 않았습니다. "선택한 다음에만 끌 수 있다"는 순서 하나로 막습니다.

## 6. 편집 모드(레이아웃 편집기)

- **화면 구성:** 아래쪽에 보관함(건물 종류·레벨별 개수)이 있고, 거기서 맵으로 끌어다 놓습니다.
- **기능:**
  - 지우개: 누르는 건물마다 보관함으로 돌아갑니다
  - 전부 치우기, 전체 한 칸 이동, 90° 회전
  - 저장(다 놓아야 저장됨)
- **용도:** 마을을 통째로 다시 짤 때 씁니다. 작은 수정은 일반 화면에서 합니다.

## 7. 카메라

- **조작:** 한 손가락으로 이동하고, 두 손가락으로 확대·축소합니다(한계 있음).
- **(미확인) 화면 가장자리 자동 이동:** 건물을 가장자리로 끌 때 화면이 따라가는지는 확인하지 못했습니다.

## 8. 장애물(나무·바위) 치우기

- **순서:** 누르면 선택되고, **비용이 적힌 [제거] 버튼**이 나옵니다. 누르면 일꾼이 와서 몇 초 만에 치웁니다. 그동안 취소하면 환불됩니다.

## 9. 우리 게임과 다른 점

| | 클래시 | 우리 게임(지금) |
|---|---|---|
| 한 손가락으로 빈 땅 끌기 | **항상 맵 이동** | 도로·구역·철거 중에는 **그리기**. 이동은 두 손가락 |
| 새 시설이 나오는 자리 | 화면 가운데에서 가장 가까운 **빈 자리** | 화면 가운데 칸. 숲·물이면 빨갛게 나옴 |
| 다른 칸 누르기 | 아무 일 없음 | 시설 미리보기가 그 칸으로 옮겨짐 |
| 줄로 놓는 것(성벽/도로) | ✓ 뒤에 **다음 칸이 자동으로 이어서** 나옴. 화살표를 끌어 길게 긋기도 됨 | 빈 땅에 그어서 그림. ✓ 뒤에는 미리보기가 사라짐 |
| 확정 뒤 | 보통 건물은 기본 상태. 성벽만 이어짐 | 시설은 기본 상태. 도로·구역·철거는 '완료'를 누를 때까지 계속 |
| 지은 건물 | 눌러서 선택 → **아래 버튼 줄** + 화살표, 선택 뒤 끌면 옮겨짐 | 눌러서 선택 → 위에 [철거] 버튼. 옮기기 없음 |
| 구역 칠하기 | 없음(클래시에 없는 기능) | 네모로 그리기 |

## 10. 클래시와 똑같이 맞추는 안 (2026-10-04 적용)

1. **한 손가락 = 언제나 맵 이동.** 미리보기(또는 그 화살표)를 잡았을 때만 미리보기가 움직입니다. 그리는 중에 두 손가락을 쓸 일이 없어집니다.
2. **새로 고른 것은 화면 가운데에서 가장 가까운, 놓을 수 있는 칸에** 나옵니다(시설·도로·구역 모두).
3. **다른 칸을 눌러도 미리보기가 움직이지 않습니다.**
4. **도로 = 성벽 방식:**
   - ✓를 누르면 1칸이 지어지고, 같은 방향으로 다음 칸 미리보기가 자동으로 나옵니다(직선은 ✓만 연타).
   - 화살표를 끌면 여러 칸을 한 번에 긋고 ✓ 한 번으로 짓습니다.
   - ✗를 누르면 끝납니다.
5. **구역·철거:** 1칸 미리보기로 시작하고, 화살표를 끌어 네모로 넓힌 뒤 ✓를 누릅니다. 그러면 기본 상태로 돌아갑니다('완료' 버튼은 없앰).
6. **지은 건물을 누르면** 아래 가운데에 버튼 줄([정보] [철거], 시설은 [옮기기]도)이 나오고 화살표가 표시됩니다.
   - 선택한 시설을 끌면 옮겨지고, 손을 떼면 저장됩니다.
   - 빨간 곳에 놓으면 원래 자리로 돌아갑니다.
   - 옮기기는 새 기능이라 따로 확인이 필요합니다.
