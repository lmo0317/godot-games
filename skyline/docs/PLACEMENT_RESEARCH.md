# 짓기 조작 조사 (3차) — 왜 계속 불편한가, 어떻게 고칠까

2026-10-06. 사용자는 클래시식으로 바꾼 뒤에도 불편하다고 했습니다. 특히 "방향 화살표를 눌러 이어 짓는 것"과 "방향이 제대로 안 따라오는 것"을 짚었습니다. 그래서 세 가지를 했습니다.
1. 폰 가로 화면(844×390)에서 직접 해 봤습니다.
2. 도로·구역이 있는 모바일 도시 게임을 조사했습니다.
3. 쿠키런: 킹덤을 조사했습니다.

앞선 조사: [UX_REFERENCE.md](UX_REFERENCE.md)(1차), [CLASH_PLACEMENT.md](CLASH_PLACEMENT.md)(2차).

## 1. 직접 해 보고 찾은 문제 (폰 가로 844×390)

1. **칸이 손가락보다 작아요.**
   - 기본 확대에서 한 칸은 약 11.5×5.8mm입니다. 손가락으로 정확히 누를 수 있는 최소 크기는 약 9mm입니다(Microsoft 연구, Apple 44pt, Material 48dp).
   - 칸 높이가 최소 크기의 60% 정도입니다. 초록 화살표는 더 작습니다.
   - 그래서 미리보기나 화살표를 잡으려 하면 자주 빗나가 맵이 움직입니다.
2. **미리보기가 버튼 밑에 나와요.** 도로가 시작되는 고속도로 끝이 왼쪽 메뉴 버튼 아래에 있어서 화살표가 가립니다. 미리보기가 나와도 화면이 그쪽으로 따라가지 않습니다.
3. **숲이 미리보기를 가려요.** 시작 지점 주변이 거의 숲이라, 나무 그림이 도로·구역 미리보기를 덮어서 어디에 깔리는지 안 보입니다.
4. **도로를 한 칸에 ✓ 한 번씩 지어요.** 다음 칸 미리보기는 ✓/✗ 버튼이나 나무에 가려집니다.
5. **방향이 손가락을 안 따라가요.**
   - 마름모 칸이라 화면에서 옆으로 밀면 칸으로는 대각선이 됩니다.
   - 처음 움직인 방향으로 꺾임을 정하는 'ㄱ자' 방식이라, 손가락이 간 길과 다르게 그려집니다.
6. **구역을 칠할 때마다 3번 눌러야 시작해요.** 칠하면 기본 상태로 돌아가서 '건설' → 탭 → 카드를 다시 눌러야 합니다.

## 2. 다른 게임들 (도로·구역 깔기)

| 게임 | 도로 | 확정 | 맵 이동 |
|---|---|---|---|
| 타운십 | 편집 모드 → 아래 막대에서 도로 → **손가락으로 그 위를 끌기**. 시작·끝 깃발을 끌어 고침 | **초록 버튼 한 번에 전부** | (미확인) |
| 메가폴리스 | 도로 버튼 → **스와이프**. 시작·끝 깃발과 초록 화살표로 방향 고침 | 철거만 ✓ | |
| 심시티 빌드잇 | 도로 버튼 → **손가락으로 그리기**(꺾임도 한 번에) | ✓ 한 번 | 두 손가락(미확인) |
| TheoTown | **시작 칸 누르고 끝 칸 누르기**. 구역도 두 모서리 누르기 | 바로 지어짐, 실행 취소 버튼 있음 | **한 손가락은 언제나 이동** |
| 포켓 시티 | 손가락으로 끌어 칠하기. "Multi"를 켜면 같은 건물을 계속 놓음 | | 불만: 화면이 손가락을 안 따라옴, 메뉴가 매번 처음으로 돌아감 |
| 미니 모터웨이 | 한 손가락으로 그리기, 지우기는 모드 버튼 | | 두 손가락 |

**공통점:**
- 도로를 한 칸씩 확정하는 게임은 없습니다. **그은 것 전체를 한 번에 확정**하거나 바로 짓고 '취소'로 되돌립니다.
- 끝점 손잡이(깃발·화살표)는 처음 그릴 때가 아니라 **고칠 때만** 씁니다.

**우리 게임과 다른 점:** 우리 게임처럼 도로를 한 칸씩 확정하는 방식은 이 게임들 중에 없습니다.

## 3. 쿠키런: 킹덤

- **편집 모드:** 왼쪽 아래 '레이아웃' 버튼으로 들어가는 **따로 된 편집 모드**가 있습니다. 화면 아래에 **보관함 막대**(건물·장식·타일·물길 탭, 접기 가능)가 있습니다.
- **길·바닥 타일:**
  - **한 손가락으로 그림 그리듯 끌어서 칠합니다.**
  - 한 번 사면 무제한으로 칠할 수 있습니다.
  - 곧은 길·모서리 모양은 저절로 맞춰집니다.
  - **칠하는 중에는 두 손가락으로 화면 이동·확대**를 합니다(2021년 업데이트로 추가).
  - 지우기는 '잔디' 타일로 덧칠하면 됩니다.
- **건물·장식:**
  - 보관함에서 골라 **직접 끌어서** 놓습니다. 옆에 작은 버튼(뒤집기·보관)이 붙습니다.
  - 같은 것을 **연달아 놓을 수 있습니다.**
  - 놓인 곳에 다른 것을 놓으면 원래 것이 보관함으로 들어갑니다.
- **치우기:** '간편 제거'를 켜고 누르거나, **네모로 끌어 여러 개를 한 번에** 보관함에 넣습니다.
- **마무리:** 실행 취소·다시 실행(3.4)이 있고, 끝낼 때 **초록 체크 하나로 저장**합니다. 빈 땅을 눌러도 편집 모드가 꺼지지 않습니다(1.2에서 고침).
- **고친 이력:** 편집 모드를 실수로 나감, 보관함이 지도를 가림, 하나씩 지우기, 칠하며 이동 불가, 되돌리기 없음. 플레이어들이 불편해한 이 점들을 업데이트마다 고쳤습니다.

## 4. 결론: 무엇을 바꾸면 편해질까

**어떤 방식을 고르든 같이 고칠 것:**
1. **짓는 동안 자동으로 확대해요.** 한 칸이 손가락보다 크게 보이게 합니다.
2. **도로를 한 칸씩 확정하지 않아요.** 그은 것 전체를 한 번에 짓습니다. 실수는 여러 번 되돌리기로 고칩니다.
3. **도로가 손가락이 지나간 칸을 그대로 따라가요.** 'ㄱ자 자동 꺾기'는 없앱니다.
4. **화면 아래 빠른 막대**(도로·주거·상업·공업·철거·시설)를 둡니다. 고른 도구는 끝낼 때까지 유지합니다. 상점은 전체 목록을 볼 때만 씁니다.
5. **미리보기가 있는 칸의 나무는 반투명하게** 해서 깔리는 곳이 보이게 합니다.
6. **✓/✗/되돌리기는 화면 오른쪽 아래 고정 자리에** 둡니다. 미리보기 위에 떠서 가리지 않게 합니다.

**두 가지 방식 중 고르기:**

| | A. 쿠키런식 편집 모드(추천) | B. TheoTown식 두 번 누르기 |
|---|---|---|
| 도로 | 한 손가락으로 그으면 지나간 칸에 깔림 | 시작 칸, 끝 칸을 차례로 누름 |
| 구역 | 한 손가락으로 네모를 끌어 그림 | 두 모서리를 차례로 누름 |
| 맵 이동 | 짓는 중에는 두 손가락 | 언제나 한 손가락 |
| 확정 | 손을 떼면 바로 지어짐 + 되돌리기, 편집 끝낼 때 ✓ | ✓ 한 번에 전부 |
| 장점 | 그림 그리듯 빠르고 직관적 | 맵 이동과 절대 안 부딪힘 |
| 단점 | 이동에 두 손가락 필요 | 긴 길은 여러 번 눌러야 함 |
