# 퍼즐블록 추가 개선 기획서 (원스토어 승인 대기 기간)

2026-09-30 작성. 원스토어 검증을 기다리는 동안 손볼 부분을 정리합니다. 다음 목표는 **앱인토스 출시**이므로, 토스 검수에 꼭 필요한 것부터 순서를 매겼습니다.

## 1. 현재 상태와 근거

| 근거 | 내용 | 시사점 |
|---|---|---|
| 봇 측정 (`tests/bench_classic.tscn`) | 가장 많이 지우는 수만 두는 봇은 한 판 중앙값 53수. 빈자리에 깔끔하게 끼우는 쪽을 조금 선호하는 봇은 **230~250수** | 차곡차곡 두는 사람에게 클래식이 너무 쉽고 판이 늘어짐 |
| 실제 플레이 기록 (9/29, 112 서버) | 이벤트 356개, 사용자 2명, 13판 시작, **끝까지 간 판 0**, 중간에 나간 판 8 | 판단하기엔 데이터가 너무 적음. 판이 길어 끝까지 안 했을 가능성은 있음(추정) |
| 앱인토스 게임 체크리스트 | 닫기(X) 버튼 겹침 금지, 진입 즉시 팝업 금지, 백그라운드 전환 시 소리 정지, 종료 확인 창, 10초 안에 첫 화면, `eval` 금지 | 아래 A 항목들이 모두 해당 |
| 안드로이드(원스토어) 빌드 | 랭킹을 숨겨서 홈 아래쪽과 게임 오버 버튼 사이에 빈 공간이 생김 | 화면 정리 필요 |
| 튜토리얼 | 없음 | 처음 하는 사람은 규칙을 스스로 알아내야 함 |

원스토어 버전은 **검증 중에는 수정할 수 없으므로**, 아래 작업은 웹(112 서버)과 앱인토스 버전에 먼저 반영하고 원스토어에는 검증이 끝난 뒤 업데이트로 올립니다.

## 2. 개선안

### A. 앱인토스 출시에 꼭 필요한 것 (필수)

| # | 항목 | 지금 | 바꿀 내용 |
|---|---|---|---|
| A1 | 오른쪽 위 버튼 겹침 | 홈과 게임 화면 오른쪽 위에 사운드·설정 버튼 | 토스 게임 화면은 오른쪽 위에 더보기·닫기(X) 버튼이 항상 떠 있음. 우리 버튼을 왼쪽이나 아래로 옮기고 Safe Area(노치, 다이내믹 아일랜드)를 비움 |
| A2 | 첫 실행 닉네임 창 | 처음 켜면 닉네임·아바타 입력 창이 바로 뜸 | 진입 즉시 입력을 강요하는 창은 반려 사유. 기본 닉네임을 자동으로 주고 바로 홈으로. 바꾸고 싶으면 프로필에서 |
| A3 | 백그라운드 소리 | 앱을 내려도 소리를 끄는 처리가 코드에 없음(확인 필요) | 내려가면 즉시 정지, 돌아오면 다시 재생. 리더보드를 열 때도 백그라운드로 바뀜 |
| A4 | 종료 확인 창 | 없음 | 게임 중 나가려 하면 "그만할까요?" 확인 |
| A5 | 로딩 시간 | 웹 빌드 약 49MB(엔진 wasm 39MB) | 10초 요건. 토스 QR 테스트로 먼저 재 보고, 넘으면 쓰지 않는 엔진 기능을 뺀 경량 엔진 빌드로 줄임 |
| A6 | `eval` 사용 | 진동 지원 확인, 서버 주소 확인에 `JavaScriptBridge.eval` | 다른 호출 방식으로 교체 |

※ 토스 SDK 연결(사용자 식별키, 토스 리더보드, `.ait` 포장)은 별도 작업입니다. 이 기획서는 게임 쪽 수정만 다룹니다.

### B. 재미·밸런스 (권장)

**B1. 클래식 후반 난이도 조정** — 2026-10-04 완료(2단계 압박, 차곡 봇 227 → 145수, 탐욕 봇 59 → 56수)
- 문제: 차곡차곡 두면 250수 가까이 버틸 만큼 쉬움. 점수 2,000~12,000 구간의 난이도 곡선이 있지만, 잘 두는 사람에게는 부족함.
- 방향: 난이도 곡선을 더 일찍, 더 세게 적용합니다. 초반 재미 세트(처음 5세트)와 시작 보드는 그대로 둡니다.
- 목표: 차곡 봇 중앙값 **250수 → 120~150수**, 탐욕 봇 53수는 유지(초보 체감 불변).
- 확인: `bench_classic`으로 전후 비교. 실제 기록이 쌓이면 다시 조정.

**B2. 첫 판 안내 (짧은 튜토리얼)** — 2026-10-04 완료
- 첫 판에서만 손가락 모양이 블록을 끌어 줄을 채우는 동작을 한 번 보여 줌. "한 줄을 채우면 사라져요" 한 줄 안내.
- 시작 보드가 이미 "딱 맞는 구멍"을 주므로, 그 구멍을 가리키면 첫 클리어까지 자연스럽게 이어짐.
- 설정에서 다시 볼 수 있게. 화면을 막는 긴 튜토리얼은 넣지 않음.

### D. 수익화 (선택 — 결정 필요)

**D1. 부활을 보상형 광고로**
- 지금은 판당 1회 무료 부활. 토스 버전에서만 "광고 보고 부활"로 바꾸면 사업자 등록 없이 출시 첫날부터 광고 수익이 생김(누적 예상수익 5천원까지 사업자 등록 유예).
- 원스토어 버전은 "광고 SDK 없음"으로 등록했으므로 **넣지 않음**.
- 광고는 미리 불러 두고, 재생 중에는 게임 소리를 멈춰야 함(토스 광고 정책).

구현 요약:

- **뽑기**: 피티 바(소프트 20뽑 유니크+ · 하드 90뽑 레전더리) 상단 노출. 럭키 롤(흰→파랑→보라→금 사다리, fakeout 50%). 마지막 플립 = 최고 등급 재배치. 자동 플립 토글(저장). 결과 요약 바 3칸 + 합성 가능 미니 썸네일 가로 스크롤 + [합성하러 가기]. 전설 중복 → 💎 유니버설 파편 1개.
- **관리**: 정렬 드롭다운(합성 가능 ↑ / 등급 ↓ / 수집순 / 이름순). 역할 필터 칩 7개. 금빛 리본 "⬆" + 테두리 호흡. 복제 바 ≥80% 노랑 깜빡·100% 금빛 "합성!". 상세 창 좌우 ◀▶ 넘기기, 다음 성급 HP·ATK 비교, [덱 넣기/빼기] / [합성·성급+1 (복제 N · 💎 M)] / [최대까지 합성 ×N] / [💎 파편으로 복제+1]. 롱프레스 400ms 드래그로 덱 편성. 전투력 롤링+색 플래시.

- **밸런스 시뮬**: `tools/sim_lane_progress.py`로 첫 클리어 보석만 쓰는 상황 체크. 24스테이지 뒤 레전더리 1명 도달. 전설까지는 재클리어·파편으로 보강(기획 의도대로).
