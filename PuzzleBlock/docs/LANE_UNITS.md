# 블록 기사단 유닛 기획서 (병사·뽑기·덱)

병사를 **게임 밖에서 모으고(뽑기) 덱 4칸을 꾸려**, 전투에서는 **덱에 넣은 병사만 소환**합니다. 냥코 대전쟁의 편성·뽑기 구조를 우리 게임 크기에 맞춘 것입니다. (2026-10-07 사용자 요청: "유닛은 게임 밖으로 나가서 유닛 덱을 구성해서 덱 안에서만 게임에서 생성 가능하게, 유닛 뽑는 가챠 화면도 필요하고 덱 구성 화면도 필요")

스테이지 구성은 [LANE_STAGES.md](LANE_STAGES.md), 전투 규칙은 [GAME_DESIGN.md](GAME_DESIGN.md) 11-1장.

## 1. 흐름

```
홈 [블록 기사단]
  └ 기사단 본부 (= 스테이지 선택 화면, 위에 보석 수)
       ├ 스테이지 칸 → 전투 (덱 4칸이 소환 버튼)
       ├ [병사 뽑기] → 뽑기 화면 (1회 100보석 / 10회 900보석)
       └ [덱 편성]   → 덱 화면 (덱 4칸 + 가진 병사 목록 + 능력치)
```

- 전투 아래 소환 줄은 **덱 4칸 그대로**입니다. 빈 칸은 회색.
- 자동 모드는 덱 안에서만 고릅니다.
- 처음엔 **기사 1명**만 있습니다. 스테이지 첫 클리어 보상으로 꼭 필요한 병사가 들어오고(아래 4장), 나머지는 뽑기로 모읍니다.

## 3. 레벨

- 같은 병사가 다시 나오면 **레벨 +1**(최대 5). 레벨마다 체력·공격 +10% (레벨 5 = +40%).
- 레벨 5에서 또 나오면 **보석 20**으로 돌려줌.
- 덱 화면과 소환 버튼에 "Lv n" 표시.

## 4. 얻는 방법

### 스테이지 첫 클리어 보상 (반드시 필요한 병사는 보상으로)

| 스테이지 | 보상 병사 | 이유 |
|---|---|---|
| 1 | 궁수 | 5스테이지 박쥐 대비 |
| 2 | 방패병 | 3스테이지 큰 고블린 무리 버티기 |
| 3 | 마법사 | 4스테이지 슬라임 떼 |
| 5 | 창병 | 11스테이지 갑옷 전에 미리 키우기 |

### 보석

| 얻는 곳 | 보석 |
|---|--:|
| 스테이지 첫 클리어 | 100 (보스 스테이지 200) |
| 새로 얻은 별 1개마다 | 20 |
| 이미 깬 스테이지 다시 클리어 | 20 |
| 레벨 5 병사 중복 | 20 |
| 처음 시작 | 200 (뽑기 2번) |

### 뽑기

| 등급 | 확률 | 병사 |
|---|--:|---|
| 일반 | 65% | 기사, 방패병, 창병, 궁수 (각 16.25%) |
| 희귀 | 28% | 석궁병, 마법사, 사제 (각 약 9.33%) |
| 영웅 | 7% | 대포병 (7%) |

- 1회 100보석, 10회 900보석(10회는 **희귀 이상 1개 보장**).
- 확률은 뽑기 화면에 항상 보여 줍니다. 보석은 게임 안에서만 얻습니다(현금 결제 없음).

## 5. 덱

- 4칸. 가진 병사만 넣을 수 있고 같은 병사는 한 칸만.
- 새 병사를 얻었을 때 빈 칸이 있으면 자동으로 들어갑니다.
- 덱이 비어 있으면 전투를 시작할 수 없습니다(기사가 항상 있으니 실제로는 생기지 않음).
