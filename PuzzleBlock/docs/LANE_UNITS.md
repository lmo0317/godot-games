# 블록 기사단 유닛 기획서 (병사·뽑기·덱)

병사를 **게임 밖에서 모으고(뽑기) 덱 4칸을 꾸려**, 전투에서는 **덱에 넣은 병사만 소환**합니다. 냥코 대전쟁의 편성·뽑기 구조를 우리 게임 크기에 맞춘 것입니다. (2026-10-07 사용자 요청: "유닛은 게임 밖으로 나가서 유닛 덱을 구성해서 덱 안에서만 게임에서 생성 가능하게, 유닛 뽑는 가챠 화면도 필요하고 덱 구성 화면도 필요")

스테이지 구성은 [LANE_STAGES.md](LANE_STAGES.md), 전투 규칙은 [GAME_DESIGN.md](GAME_DESIGN.md) 11-1장.

## 1. 흐름

```
홈 [블록 기사단]
  └ 기사단 본부 (= 스테이지 선택 화면, 위에 보석 수)
       ├ 스테이지 칸 → 전투 (덱 4칸이 소환 버튼)
       ├ [병사 뽑기] → 뽑기 화면 (1회 100보석 / 10회 900보석)
       └ [덱 편성]   → 덱 화면 (덱 4칸 + 가진 병사 목록 + 능력치)
```

- 전투 아래 소환 줄은 **덱 4칸 그대로**입니다. 빈 칸은 회색.
- 자동 모드는 덱 안에서만 고릅니다. 성 가까이 온 적이 날아다니는 적뿐이면 기사 대신 원거리 병사(석궁병 > 궁수 > 마법사)를 뽑습니다.
- 처음엔 **기사(근거리)와 궁수(원거리)** 2명이 덱에 있습니다. 날아다니는 박쥐는 근거리 병사가 못 때려서, 원거리 병사 하나는 처음부터 줍니다(같은 날 "궁수가 없으면 어떻게 깨냐"는 피드백). 예전 저장(기사만)에도 궁수를 넣어 줍니다. 나머지 병사는 모두 보석으로 뽑습니다.
- **스테이지가 끝나면(클리어든 실패든) 결과 창에서 본부로 돌아갑니다.** 본부에서 보석을 쓰고 덱을 정비한 뒤 다음 스테이지를 고릅니다.
- 본부·뽑기·덱 화면 맨 위에 **재화 바**(보석, 모은 별).

## 3. 성급과 합성

같은 날 사용자 요청("캐릭터 합성해서 성급 올리기, 캐릭터마다 성급, 성급마다 배경색 다르게, 노멀 레어 유니크 레전더리 신화 전설, 이펙트")으로 레벨을 **성급 6단계**로 바꿨습니다.

| 성급 | 카드 색 | 테두리 | 카드 효과 |
|---|---|---|---|
| 노멀 | 회색 | 철 + 리벳 | – |
| 레어 | 파랑 | 강철 + 사파이어 | – |
| 유니크 | 보라 | 은 + 자수정 | 빛줄기가 가끔 지나감 |
| 레전더리 | 주황 | 금 + 토파즈·잎 장식 | + 작은 별이 반짝임 |
| 신화 | 빨강 | 진한 금 + 루비·가시 | + 카드가 빛나며 맥동 |
| 전설 | 금색 | 밝은 금 + 다이아·날개 | + 빛과 반짝이가 무지개색으로 돎 |

- 같은 병사를 또 뽑으면 **복제 +1**. 복제를 모아 **합성**하면 성급이 하나 오릅니다.
- 다음 성급까지 필요한 복제: 노멀→레어 1, 레어→유니크 2, 유니크→레전더리 3, 레전더리→신화 4, 신화→전설 5.
- 성급마다 체력·공격(사제는 회복량도) **+25%** (시작 성급 기준, 노멀 기사가 전설이 되면 +125%).
- 전설에서 또 나오면 보석 20으로 돌려줌.
- 합성하면 카드가 번쩍이고 별이 터지며 "○○ 달성!" 배너가 뜸.
- 예전 저장의 레벨(1~5)은 `레벨 − 1`개의 복제로 바뀜.

## 4. 얻는 방법

### 병사는 뽑기로만

같은 날 사용자 요청("보상은 보석으로만 받게 하고 보석으로 직접 뽑게")으로 스테이지 보상 병사를 없앴습니다. 처음엔 기사·궁수 2명, 나머지는 모두 뽑기로 얻습니다. 시작 보석은 300(뽑기 3번).

### 보석

| 얻는 곳 | 보석 |
|---|--:|
| 스테이지 첫 클리어 | 150 (보스 스테이지 300) |
| 새로 얻은 별 1개마다 | 30 |
| 이미 깬 스테이지 다시 클리어 | 50 |
| 진 스테이지 | 요새를 깎은 만큼, 최대 60 |
| 전설 병사 중복 | 20 |
| 처음 시작 | 300 (뽑기 3번) |
| 홈 보석 옆 **+** 버튼 (테스트용, dev 브랜치만) | 누를 때마다 1000 |

**+ 버튼은 2026-10-08 사용자 요청으로 넣은 테스트용**입니다. dev를 master(스토어·토스)에 합칠 때 `HomeScreen.DEV_GEMS = 0`으로 꺼야 합니다(공짜 보석은 밸런스를 깸).

첫 클리어 보석만 모두 쓰면 덱이 스테이지마다 얼마나 커지는지 계산해 난이도(예상 성급)를 정했습니다 — [LANE_STAGES.md](LANE_STAGES.md) 2장. 보스에서 막히면 다시 깨기(50)·진 판(최대 60)으로 조금씩 더 키웁니다.

### 전투력

덱 병사마다 100 + 25 × 성급(노멀 0, 레어 1 … 전설 5)을 더한 값. 본부 위와 스테이지마다 권장 전투력과 비교해 보여 주고(모자라면 빨강), 병사·덱 화면 덱 칸 위에도 표시합니다.

### 뽑기

| 시작 성급 | 확률 | 병사 |
|---|--:|---|
| 노멀 | 65% | 기사, 방패병, 창병, 궁수 (각 16.25%) |
| 레어 | 28% | 석궁병, 마법사, 사제 (각 약 9.33%) |
| 유니크 | 7% | 대포병 (7%) |

- 1회 100보석, 10회 900보석(10회는 **레어 이상 1개 보장**).

### 뽑기 연출 (2026-10-08)

"뽑기가 너무 부실하다 — 뽑은 병사를 보여 주고, 무엇을 뽑았는지, 뽑을 때마다 효과" 요청. 게임 기획자 조사: 인기 뽑기는 **① 기다리는 동안 등급을 예고**하고(원신의 별똥별 색), **② 가끔 낮은 색에서 높은 색으로 바뀌는 순간**이 가장 기억에 남고, **③ 높은 등급일수록 빛·흔들림·소리를 키우고**, **④ 반복해서 보면 지루하니 넘기기**와 **⑤ 끝에 모아 보기**를 둠.

1. **제단**: 소환 제단 위에 소용돌이 포털, 뒤에 천천히 도는 광선, 제단에서 반짝이가 피어오름. 아래에 확률표(양피지), [1회 뽑기 100] [10회 뽑기 900 · 레어 이상 1명 보장].
2. **충전**(1회 1.1초, 10회 1.5초): 반짝이가 사방에서 포털로 빨려 들고 빛 기둥이 솟음. 빛 색 = 이번에 나올 가장 좋은 병사(흰 노멀 / 파랑 레어 / 보라 유니크). 유니크면 반쯤 파랑에서 시작했다가, 레어 이상이면 30% 흰색에서 시작했다가 **도중에 색이 바뀜**(번쩍임·흔들림·소리). 끝에 흰 번쩍임.
3. **한 명씩 공개**: 어두운 화면에 그 등급 색 광선이 돌고, 병사 카드가 동전처럼 돌며 크게(도트 ×5) 나옴. 이름·성급·역할·설명, 그리고 **NEW!** 리본(소리) 또는 "+1 복제 · 합성까지 1/2"("합성할 수 있어요!"는 금색). 레어는 별빛 폭발·번쩍임, 유니크는 더 큰 폭발·흔들림·팡파르. 누르면 다음, 가만히 두면 넘어감(10회의 노멀 복제는 1초, 새 병사·레어 이상은 더 오래). [건너뛰기]는 바로 요약으로.
4. **요약**: "뽑기 결과" 판에 10장 카드(NEW!/+1 복제), "새 병사 n명 · 복제 m개", 합성할 수 있는 병사 이름과 **[합성하러 가기]**(병사·덱 화면으로), [확인].
- 효과음: `g_charge`, `g_shift`, `g_reveal_0~2`, `g_new` (`tools/generate_sfx.py`, 파일마다 -6dBFS).
- 연출 중에는 뽑기·본부 버튼을 잠금.
- 확률은 뽑기 화면에 항상 보여 줍니다. 보석은 게임 안에서만 얻습니다(현금 결제 없음).

## 5. 덱

- 4칸. 가진 병사만 넣을 수 있고 같은 병사는 한 칸만.
- 새 병사를 얻었을 때 빈 칸이 있으면 자동으로 들어갑니다.
- 덱이 비어 있으면 전투를 시작할 수 없습니다(기사가 항상 있으니 실제로는 생기지 않음).
