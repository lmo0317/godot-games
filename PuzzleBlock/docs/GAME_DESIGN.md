# 1부 · 원작 분석

## 01. 원작 개요

싱가포르 기반 Hungry Studio가 2022년에 출시한 8×8 블록 퍼즐입니다. 출시 2~3년 뒤에 폭발적으로 성장해 2024년과 2025년 연간 모바일 게임 다운로드 최상위권에 올랐습니다. 새로운 장르를 만든 게임이 아니라, 이미 있던 "블록 퍼즐"을 가장 잘 다듬은 게임에 가깝습니다.

| 지표 | 값 |
|---|---|
| 일간 활성 사용자(DAU) | 약 7,000만 (2025년 보도) |
| 월간 활성 사용자(MAU) | 약 3억 |
| 누적 다운로드 | 8.7억 이상 |
| 월 광고 매출 | 약 $17.5M (추정). 인앱결제는 미미 |

> 수치는 업계 보도·분석 추정치입니다. 출처는 문서 끝에 있습니다.

- **모드**: 끝없이 최고 점수에 도전하는 **클래식**, 목표가 정해진 스테이지를 깨는 **어드벤처**.
- **수익 모델**: 전면·배너 광고와 보상형 광고(부활) 중심. 인앱결제 매출은 거의 없습니다. 게임 설계가 "광고를 보면서도 계속하고 싶은 판"을 만드는 데 맞춰져 있다는 뜻입니다.
- **개발 방식**: AI 봇 시뮬레이션과 A/B 테스트로 블록 모양, 점수 체계, 시각 피드백, 부활 방식을 실험하고, 특정 구간의 이탈을 데이터로 찾아 고칩니다. 동적 난이도 조절(DDA)로 플레이어마다 체감 난이도를 맞춥니다.

## 02. 핵심 루프

한 턴은 10초 남짓이고, 판단 → 행동 → 보상이 짧게 반복됩니다.

```
보드 읽기 → 3개 블록 확인 → 순서 계획 → 드래그 배치 → 라인 폭발 → 점수·콤보 ─┐
    ↑                                                                    │
    └──────────────────────── 3개를 다 놓으면 새 세트 ←───────────────────┘

실패 분기: 놓을 곳 없음 → 부활 제안 → 게임오버 → 최고 점수와 비교 → "한 판 더"
```

## 03. 재미 요소 8가지

원작의 재미는 새로운 규칙에서 나오지 않습니다. 조작 부담을 걷어내고 **"어디에 놓을까"라는 판단 하나**만 남긴 뒤, 그 판단에 보상을 크게 붙인 것이 핵심입니다.

| # | 재미 요소 | 내용 | 효과 |
|---|---|---|---|
| 1 | 3초 만에 이해되는 규칙 | 회전·중력·시간 제한 없음. 세로 화면 한 손 조작, 언제든 중단 가능 | 진입 장벽이 거의 없음 |
| 2 | 3개 한 세트가 만드는 계획 | 3개가 동시에 보이고 순서는 자유, 다음 세트는 모름 → 매 턴이 작은 퍼즐 | 지치지 않는 적당한 인지 부하, 효능감 |
| 3 | 딱 맞는 쾌감과 미완성 줄 | 빈자리에 정확히 맞는 만족감. 7/8 줄은 끝내지 못한 숙제처럼 신경 쓰임 | 완결 욕구, 목표가 저절로 생김 |
| 4 | 긴장과 해소의 리듬 | 보드가 차오르며 불안, 줄이 터지며 한순간에 해소. 톱니 모양 반복 | 매 판이 작은 위기와 탈출의 이야기가 됨 |
| 5 | 위험을 건 콤보 | 당장 지울지, 모아서 동시 폭발·연속 콤보를 노릴지 선택 | "쉬운 규칙, 깊은 전략" |
| 6 | 행동보다 큰 반응(주스) | 파티클, 올라가는 음정, 칭찬 문구, 화면 흔들림 | 즉각적인 감각 보상 |
| 7 | 다음 세트 기대와 보이지 않는 도움 | "1×4 나와라" 하는 기대. 막힐 때 필요한 블록이 우연처럼 나옴(DDA) | 변동 보상의 기대감, 몰입 유지. 도움을 실력으로 느낌 |
| 8 | 내 탓이라서 한 판 더 | 게임오버가 "아까 저기 놓지 말걸"로 느껴짐. 최고 점수 상시 노출, 부활 기회 | 가장 강한 리텐션 장치 |

## 04. 긴장과 해소 곡선

한 판 동안 보드 점유율은 차오르다 줄이 터지며 떨어지는 톱니 모양으로 움직입니다(개념도, 실측 아님).

```
100% ┤
 70% ┤─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─╱╲─ ─ ─ ─ ─ ─ ─╱  ← 위기 구간 (생성기 개입)
     │                  ╱╲       ╱  ╲       ╱
 50% ┤            ╱╲   ╱  ╲    ╱     ╲    ╱
     │      ╱╲   ╱  ╲ ╱    ╲  ╱       ╲  ╱
  0% ┼─────╱──╲─╱────────────────────────────────── 배치 횟수 →
          1줄      2줄 동시        위기 탈출
```

- 톱니의 **떨어지는 폭**이 보상이고, **70% 위에서 머무는 시간**이 긴장입니다.
- 위기 구간에서 너무 오래 버티게 하면 피로해지고, 너무 빨리 끝나면 억울해집니다.

## 05. 재미를 깨는 요인

| 요인 | 왜 문제인가 | 대응 원칙 |
|---|---|---|
| 놓을 수 없는 3개 연속 | 게임오버가 "운 탓"이면 재도전 대신 이탈 (재미 요소 8 붕괴) | 세트 생성 시 3개를 순서대로 모두 놓을 수 있는지 검증 |
| 과도한 광고 | 원작에 대한 가장 흔한 불만. 흐름이 끊기면 루프가 멈춤 | 광고를 넣더라도 판 사이에만, 부활은 선택형 |
| 끝나지 않는 판 | 숙련자는 한 판이 수십 분, 후반이 단조로움 | 점수·콤보가 높을수록 큰 블록 비중을 올려 압박 유지 |
| 피드백 과잉 | 모든 행동에 최대 연출을 주면 큰 순간이 묻힘 | 연출 강도를 줄 수·콤보에 비례, 설정에서 끌 수 있게 |
| 보이는 도움 | 도와주는 것이 티 나면 성취감이 사라짐 | 보조 확률을 100%로 두지 않고 역할 슬롯 순서를 섞음 |

### 디자인 원칙

기능을 추가하거나 수치를 바꿀 때 이 4가지에 맞는지 먼저 확인합니다.

1. **설명 없는 첫 판** — 튜토리얼 없이 첫 판을 시작하고 이해할 수 있어야 한다. (재미 요소 1·2)
2. **공정한 긴장** — 게임오버는 항상 플레이어의 선택 결과로 느껴져야 한다. 생성기는 돕되 티 나지 않게. (재미 요소 7·8)
3. **모든 클리어는 축제** — 줄 수와 콤보에 비례해 소리·빛·흔들림이 커진다. (재미 요소 4·6)
4. **한 판 더** — 게임오버에서 다시 시작까지 한 번의 탭. 최고 점수와 순위를 바로 보여 준다. (재미 요소 8)

## 09. 점수와 콤보

```
배치 점수     = 놓은 칸 수
클리어 점수   = ⌊10·L² × (1 + 0.45·C)⌋ + 15·C + 5·C²
퍼펙트 클리어 = round(300 × (1 + 0.45·C))   ← 클리어 후 보드가 완전히 비면 추가
콤보 피버     = C ≥ 5이면 클리어 점수 × 1.5 (소수점 버림)
```

`L` = 한 번에 지운 줄 수(가로+세로), `C` = 이번 클리어를 포함한 콤보 수(첫 클리어 = 1).

| 상황 | L | C | 클리어 점수 | 클리어 팝업 |
|---|--:|--:|--:|---|
| 첫 1줄 | 1 | 1 | 34 | +34 |
| 첫 클리어가 2줄 동시 | 2 | 1 | 78 | Good! |
| 3콤보째 1줄 | 1 | 3 | 113 | Good! · COMBO ×3 |
| 5콤보째 1줄 | 1 | 5 | 232 | Great! · COMBO ×5 |
| 5콤보째 3줄 동시 | 3 | 5 | 492 | Great! · COMBO ×5 |
| 10콤보째 1줄 | 1 | 10 | 705 | Excellent! · COMBO ×10 |
| 첫 1줄로 보드 전체 비움 | 1 | 1 | 34 + 435 | +34 · PERFECT! |

클리어 팝업은 지운 자리에서 최대 세 줄이 차례로 튀어나옵니다: 영어 칭찬 문구, `COMBO ×N`(C ≥ 2), `+점수`. 칭찬 단계는 줄 수 단계(2줄 Good! · 3줄 Great! · 4줄 Excellent! · 5줄 이상 Amazing!)와 콤보 단계(3·5·8·12·16콤보에서 한 단계씩, 16콤보는 Unbelievable!) 중 높은 쪽입니다. 1줄 단독 클리어는 점수만 작게 뜹니다.

보드 위 콤보 배지는 `COMBO ×N`과 3칸짜리 막대(줄을 못 지우고 남은 수)로 보여 줍니다. 마지막 1칸은 빨간색입니다.

### 콤보 유지: 3수 유예

- 줄을 지우면 콤보 +1, 유예를 3으로 채움.
- 줄을 못 지운 배치마다 유예 −1, 0이 되면 콤보 종료.
- 배너에 `● ● ○` 형태로 남은 유예 표시, 1회 남으면 붉게 깜박여 경고.

> **원작과의 차이.** 원작의 콤보 유지 규칙은 커뮤니티 자료마다 다릅니다("한 번이라도 못 지우면 초기화" vs "3수 안에 한 번 지우면 유지"). 우리는 **3수 유예**를 채택합니다. 초보자도 콤보를 경험할 수 있고, "지금 지울까, 모아서 터뜨릴까"라는 재미 요소 5의 선택 폭이 넓어지기 때문입니다.

### 퍼펙트 클리어와 테마 변경

Block Blast처럼 보드를 전부 비우면(퍼펙트 클리어) 보너스 점수와 함께 **게임 화면 테마가 다음 것으로 바뀝니다.** 배경 그림(Gemini로 그림), 보드 색·테두리, 빈 칸 색이 약 0.9초에 걸쳐 넘어가고 "○○ 테마" 문구가 뜹니다. 블록 스킨은 설정에서 고른 그대로 두고, 점수에는 영향이 없습니다. 새 판은 첫 테마에서 시작합니다.

테마 7종: 미드나잇 → 오로라 → 오션 → 선셋 → 포레스트 → 코스모스 → 엠버 (`scripts/board_themes.gd`, `assets/art/`).

퍼펙트 클리어가 너무 드물면 볼 수 없는 기능이 되므로, 클래식에서 기회를 만듭니다.
- **깨끗한 시작 보드:** 구멍 보드 중 약 3분의 1(전체 판의 약 6분의 1)은 다른 블록 없이 두 줄과 구멍만 둡니다. 첫 세트에 구멍에 맞는 블록을 주므로, 첫 수에 두 줄이 지워지며 보드가 비고 테마가 바뀝니다.
- **게임 중 기회:** 보드에 블록이 24칸 이하로 남으면 세트마다 50% 확률로(처음 8세트는 항상), 세 블록 안에 보드를 비울 수 있는 세트를 찾아(빔 탐색) 줍니다. 탐색은 "줄 단위로 채워 보드를 비우는 데 필요한 칸 수"가 적은 상태부터 이어 갑니다. 단순히 작은 블록부터 놓으면 줄이 맞지 않아 비울 수 있는 세트를 놓치기 때문입니다.

측정(봇 200판): 퍼펙트 클리어가 있는 판 0% → 17%, 판당 0.22회. 탐색 순서를 바꾸고 초반에 항상 찾도록 한 뒤(2026-10-03) 21%, 판당 0.32회. 탐색 시간은 PC 기준 평균 약 8ms입니다.

### 콤보 피버

5콤보부터 **피버** 상태가 됩니다. 줄 클리어 점수가 1.5배가 되고, 보드 테두리와 배경이 주황빛으로 맥동하며, 콤보 배지가 주황색 `FEVER ×6`으로 바뀝니다. 들어가는 순간 효과음·진동이 나오고, 클리어 팝업이 사라진 뒤 `FEVER!` 문구가 한 번 나옵니다. 콤보가 끊기면 해제됩니다. 콤보를 길게 이어가는 쪽을 점수로 확실히 보상해 재미 요소 5(위험을 건 콤보)를 강화합니다.

### 신기록 도전 표시

클래식·챌린지에서 이 판을 시작할 때의 최고 점수를 목표로 삼습니다.
- 게임 중: BEST 상자에 "신기록까지 1,760"과 금색 진행 바. 넘는 순간 "NEW BEST!" 문구·효과음·진동, 이후 "신기록 경신 중!"
- 게임오버: 신기록이 아니면 "BEST: 5,000 · 320점 부족"
- 첫 판(기록 0)에는 표시하지 않습니다.

목표까지 얼마 남았는지 보여 주는 장치로, 재미 요소 8(한 판 더)을 강화합니다.

## 10. 블록 생성과 난이도

재미 요소 7을 담당하는 핵심 시스템입니다. 3개를 뽑을 때마다 보드를 분석해 각 블록이 지금 얼마나 "필요한지" 점수를 매깁니다.

### 보드 친화도 점수 (가능한 모든 위치 중 최고값)

| 조건 | 점수 |
|---|--:|
| 어딘가에 놓을 수 있음 | +5 |
| 줄을 완성함 (줄당) | +125 |
| 줄을 7/8로 만듦 | +28 |
| 줄을 6/8로 만듦 | +14 |
| 어디에도 놓을 수 없음 | −1 (제외) |

최종 가중치 = `기본 가중치 × (1 + 친화도 × 0.18)`. 기본 가중치는 도미노 4.5, 3줄 3.8, 2×2 3.5처럼 빈틈 메우기 좋은 블록이 높고, S/Z 0.7, 큰 L 0.8처럼 부담스러운 블록이 낮습니다.

### 슬롯별 역할

| 슬롯 | 선택 규칙 |
|---|---|
| A · 해결사 | 도미노, 작은 코너, 2×2 중에서 가중치 추첨 |
| B · 라인 완성 | 위기이거나, (콤보 중 또는 점유율 40%↑)일 때 85%(유예 1회 남으면 95%) 확률로 줄을 지울 수 있는 블록. 아니면 75% 확률로 7/8·6/8 줄을 채우는 블록. 그 외 직선·T·L·S/Z |
| C · 압박 | 위기에는 4칸 이하 안전 블록만. 여유(점유율 45%↓)이고 점수 400↑ 또는 2콤보↑이면 50% 확률로 3×3·큰 L·5줄. 그 외 전체 가중치 추첨 |

- 위기 판정: 점유율 70% 이상 또는 놓을 수 있는 모양이 4종 이하.

### 점수에 따른 난이도 곡선 (클래식만)

압박도 `p = clamp((점수 − 2,000) / 10,000, 0, 1)`. 2,000점까지는 변화가 없고 12,000점에서 최대입니다.

| 항목 | p = 0 | p = 1 |
|---|--:|--:|
| 줄을 지울 블록을 챙겨 줄 확률 (유예 1회 남음) | 85% (95%) | 45% (65%) |
| 7/8·6/8 줄 채움 블록 확률 | 75% | 40% |
| 친화도 가중 계수 | 0.18 | 0.072 |
| 해결사 슬롯이 일반 추첨으로 바뀔 확률 | 0% | 50% |
| 큰 블록 허용 점유율 / 확률 | 45% / 50% | 60% / 80% |

위기 구조(줄을 지울 블록 지급)는 압박과 상관없이 유지합니다. 어드벤처와 챌린지에는 적용하지 않습니다.

### 2단계 압박 (15,000점 이후, 클래식만)

차곡차곡 두는 사람은 1단계 최대 압박에서도 판이 끝나지 않아(봇 중앙값 227수, 점수 17만), 15,000점부터 45,000점까지 2단계 압박 `o`(0→1)를 더합니다. `pressure_for_score()`가 0~2를 돌려주고, 1을 넘는 부분이 `o`입니다.

| 항목 | o = 0 | o = 1 |
|---|--:|--:|
| 줄을 지울 블록·7/8 줄 채움 블록 확률 | 1단계 값 | 1단계 값 × 0.1 |
| 친화도 가중 | 1단계 값 | 0 (기본 가중치만) |
| 해결사 슬롯이 일반 추첨으로 바뀔 확률 | 50% | 100% |
| 큰 블록 허용 점유율 / 확률 | 60% / 80% | 70% / 100% |
| 세 블록을 모두 놓을 수 있는지 확인을 건너뛸 확률 | 0% | 80% |

마지막 항목이 핵심입니다. 각 블록은 지금 보드에 놓을 수 있지만, 순서를 잘못 고르면 셋을 다 못 놓을 수 있습니다(원작과 같음). 위기(점유율 70%↑ 또는 놓을 수 있는 모양 4종 이하)일 때는 확인을 건너뛰지 않습니다.

측정은 `tests/bench_classic.tscn`(봇 200판)으로 합니다. 기본 봇은 줄을 지우면서 빈자리에 깔끔하게 끼우는 쪽을 조금 선호하는 "차곡 봇"이고, `BENCH_SNUG=0`이면 지우는 것만 보는 "탐욕 봇"(초보)입니다.

2026-10-04 2단계 압박 결과:

| | 탐욕 봇 판 길이 중앙값 / 상위 25% | 탐욕 봇 점수 중앙값 | 차곡 봇 판 길이 중앙값 / 상위 25% | 차곡 봇 점수 중앙값 |
|---|---|---|---|---|
| 이전 | 59 / 80수 | 9,127 | 227 / 446수 | 178,619 |
| 2단계 압박 | 56 / 74수 | 9,127 | 145 / 203수 | 61,351 |

2026-09-29 결과(탐욕 봇):

| | 판 길이 중앙값 / 상위 25% | 점수 중앙값 / 상위 10% | 콤보 중앙값 / 상위 10% |
|---|---|---|---|
| 이전 | 53 / 86수 | 3,467 / 18,149 | 8 / 16 |

### 초반 "딱 맞는" 세트 (클래식만)

필요한 블록만 주면 초반이 밋밋합니다. 초반 재미는 블록이 빈자리에 딱 들어가 두 줄이 한 번에 터지거나, 세 블록을 이어 놓으며 연달아 지우는 순간에서 나옵니다.

**시작 보드의 구멍.** 판의 절반은 인접한 두 줄을 한 블록 모양(2×2, 코너, T, S/Z, L 등)만 비우고 채운 보드로 시작합니다. 그 블록을 넣으면 두 줄이 동시에 지워집니다. 나머지 절반은 기존 무작위 시작 보드입니다.

**재미 점수로 고른 세트.** 처음 8세트(점수 6,000 미만)는 후보 세트를 여러 개 만들어 세 블록을 놓는 순서를 탐색(빔 4)하고, 플레이어가 눈앞의 좋은 수(아래 표)를 둔다고 보고 그 수순과 결과로 순위를 매깁니다.

| 수마다 | 점수 |
|---|--:|
| 지운 줄 L | L² × 30 |
| 앞 수에 이어 또 지움 | +20 |
| 주변이 85% 이상 막힌 자리에 끼움 | 칸당 +6 |
| 빈 공간을 정확히 메움 | +12 |
| 퍼펙트 클리어 | +200 |

콤보와 퍼펙트 클리어를 위해 그 수순이 어디로 이어지는지도 봅니다.

| 수순 결과 | 점수 |
|---|--:|
| 줄을 지운 수 | 수마다 +25 |
| 콤보가 끊김(3수 유예 소진) | −120 |
| 퍼펙트 클리어 | +150 (위 +200에 더해) |
| 세트가 끝난 뒤 남은 유예 | 1수당 +8 |
| 6/8·7/8 찬 줄(다음 세트에서 지울 줄) | 줄당 +10, 최대 4줄 |
| 보드를 비우는 데 필요한 칸 수(줄 단위로 채울 때) | 40칸보다 적은 만큼 칸당 +6 |

후보 세트:
- **필요한 블록 세트(4개):** 첫 블록이 줄을 지우고, 그 결과 보드에서 다음 블록이 또 줄을 지우는 식으로 차례로 고른 세트. 블록마다 가장 많이 지우는 자리 기준, 기본 가중치 × (1 + 지우는 줄 수)로 추첨합니다.
- **보드를 비우는 세트:** 블록이 24칸 이하일 때 세 블록 안에 보드를 비울 수 있는 세트가 있으면 순위 없이 바로 줍니다.
- 두 줄 이상을 한 번에 지울 수 있는 블록이 있으면 그 블록을 넣은 후보를 따로 만듭니다(최대 4개).
- 그 밖에 무작위 세트 4개(3분의 1은 필요 기반 생성기).

고르는 규칙: 콤보를 이어가는 후보가 있으면 콤보가 끊기는 후보는 빼고, 두 줄 구멍에 맞는 블록이 든 후보가 있으면 그 안에서 고릅니다.
- 크기가 섞인 세트에 보너스, 작은 블록만 여럿이면 감점.
- 1등 60%, 2등 25%, 3등 15%로 골라 판마다 달라지게 합니다.
- 첫 세트에는 바로 줄을 지우는 블록을 계속 보장합니다. 순차 배치 가능 여부도 그대로 확인합니다.

측정(수순 탐색 봇 200판, 처음 15수 기준, 2026-09-29):

| | 두 줄 이상 동시 클리어 | 연속 클리어 | 딱 맞게 끼움 |
|---|--:|--:|--:|
| 이전 | 0.17 | 1.39 | 1.28 |
| 시작 구멍만 | 0.38 | 1.40 | 1.08 |
| 시작 구멍 + 재미 세트 | 0.70 | 1.85 | 1.36 |

구멍이 있는 보드는 거의 모두(489판 중 488판) 첫 세트에 그 구멍에 맞는 블록이 나옵니다.

콤보·퍼펙트 클리어 반영(2026-10-03, 수순 탐색 봇 200판, 처음 24수 기준. 봇은 두 버전 모두 처음 8세트를 같은 방식으로 읽음):

| | 최대 콤보 중앙값 / 상위 25% | 콤보 끊김 | 퍼펙트 클리어 (판당, 있는 판) | 연속 클리어(처음 15수) | 딱 맞게 끼움(처음 15수) |
|---|---|--:|---|--:|--:|
| 이전 | 6 / 8 | 1.72 | 0.18, 14% | 1.60 | 1.42 |
| 콤보·퍼펙트 반영 | 7 / 10 | 1.36 | 0.29, 19% | 2.17 | 0.85 |

판 전체로는 퍼펙트 클리어가 판당 0.20 → 0.32회입니다. 딱 맞게 끼우는 순간은 줄었습니다. 초반 세트 생성 시간은 PC 기준 평균 약 24ms → 41ms, 시작 보드는 약 1ms입니다.
- 뽑은 3개는 순서를 섞어 어느 칸이 어떤 역할인지 알 수 없게 합니다.

| 사건 | 시각 | 사운드 |
|---|---|---|
| 블록 집기 | 실제 크기로 확대, 손가락 위로 띄움 | pickup |
| 드래그 중 | 고스트 미리보기, 완성될 줄 금색 반짝임 | — |
| 배치 | 찌그러졌다 펴지는 탄성 바운스 | place |
| 1줄 클리어 | 연쇄 폭발, 흔들림 4, COOL | clear |
| 2줄 / 3줄 / 4줄+ | 흔들림 8 / 13 / 19, 문구 확대 | clear + 장3도 / + 완전5도 / + record |
| 콤보 N | 배너, 3콤보↑ 시안 오라, 5콤보↑ 금색 오라 | 콤보 음이 온음계로 한 단계씩 상승 |
| 배치 불가 | 블록 흐리게(투명도 0.42) | invalid (복귀 시) |

진동(지원 기기, 설정에서 끌 수 있음): 집기 8ms · 배치 12ms · 클리어 `25 + 15·L + 3·C`ms(최대 90) · 부활 100ms · 게임오버 120ms · 퍼펙트 클리어 160ms. Web은 세기를 지정할 수 없어 시간으로 강도를 구분합니다.
| 퍼펙트 클리어 | 보드 전체 플래시, 흔들림 24, PERFECT! 문구 | clear(저음) + record 장3화음 |
| 게임오버 · 신기록 | 모달 페이드인, NEW BEST 배지 | gameover · record |

### 첫 판 안내

처음 하는 사람의 첫 클래식 판에서만, 손가락 그림이 트레이의 블록을 집어 줄을 완성하는 자리로 끌어다 놓는 동작을 반복하고 보드 아래에 "블록을 끌어다 한 줄을 채우면 사라져요"를 띄웁니다. 시작 보드와 첫 세트가 이미 바로 지울 수 있는 블록을 주므로, 지금 가장 많은 칸을 지우는 블록과 자리를 가리킵니다.

- 입력을 막지 않습니다. 블록을 잡으면 사라지고, 줄을 못 지우고 놓으면 다시 나옵니다.
- 첫 줄을 지우면 끝나고 다시 나오지 않습니다. 세트 3개 동안 줄을 안 지워도 끝냅니다.
- 이미 판을 해 본 사람(업데이트 전 기록 포함)에게는 나오지 않습니다. 설정의 "게임 방법 다시 보기"로 새 클래식 판에서 다시 볼 수 있습니다.
- 챌린지와 어드벤처에는 나오지 않습니다. 화면을 막는 창이 아니므로 토스의 "진입 즉시 팝업 금지"에 걸리지 않습니다.

## 11-1. 블록 기사단 (냥코 대전쟁·팔라독식, dev 브랜치)

홈의 "블록 기사단" 카드로 시작합니다. 몬스터 배틀(퍼즐앤드래곤식)이 "애매"하다는 평가를 받고, "포인트를 모아 버튼으로 병사를 추가하는 디펜스"(냥코 대전쟁·팔라독)로 바꿨습니다(2026-10-06). 처음엔 수마다 진행(블록 하나 = 한 턴)으로 만들었다가, 같은 날 사용자 요청으로 **실시간 전투**로 바꿨습니다. 블록을 깨서 번 돈으로 병사를 더 뽑습니다. "전투가 재미없다"는 피드백 뒤 라인 디펜스 조사([BATTLE_RESEARCH.md](BATTLE_RESEARCH.md))의 변경 8가지(손맛, 넉백, 소환 대기시간, 대포, 웨이브·보스, 지갑·수입 UP, 상성 적, 돌격/수비)를 모두 넣었습니다(2026-10-07).

| 규칙 | 내용 |
|---|---|
| 퍼즐 | 클래식과 똑같음. 블록 지급은 적응형 생성기, 압박 0.3 고정 |
| 화면 | 위쪽 메뉴 줄을 숨기고 화면 맨 위부터 **470px** 옆에서 본 전장(왼쪽 내 성, 오른쪽 적 요새 — 둘 다 반쯤 화면 밖, 병사·몬스터는 도트 **1.4배**, 체력 바는 건물 아래 땅 위 — 오른쪽 위는 토스 버튼 자리), 전장 왼쪽 위에 홈·설정·소리, 돌격/수비 버튼, 금화. **소환 줄 없음**(2026-10-08 "자동을 기본으로, 유닛 뽑는 UI 제거, 화면을 크게, 블록 줄을 내려서"): 자동이 소환·수입 UP·대포를 다 함. 그 자리를 전장에 주고, 보드 95%(위 478px부터)·트레이 85%(1092px부터, 더 아래로) (이 모드에서만, `MainGame._apply_layout()`) |
| 실시간 | 유닛은 저마다의 속도로 걷다가 사거리 안에 적(또는 상대 성)이 오면 멈춰서 공격 간격마다 때림. 유닛끼리 겹칠 수 있어 무리가 같이 싸움(줄을 서면 맨 앞만 싸워서 전투가 막혔음). 설정 창이 열려 있는 동안은 멈춤 |
| 손맛 | 맞으면 하얗게 번쩍·납작해졌다 튕김·타격 불꽃(큰 타격은 충격 고리)·근접은 베기 자국·튀어 오르는 데미지 숫자, 원거리는 화살·볼트·화염구·빛 구슬이 날아가 맞을 때 피해, 큰 타격은 전장만 흔들림, 소환은 떨어지며 먼지, 회복은 초록 십자, 크게 맞으면 뒤로 튕김(넉백), 죽으면 회전하며 날아가고 픽셀 조각이 튐, 강타·대포·보스에 짧은 멈춤, 성이 맞으면 흔들림·붉은 번쩍임. 전투 소리 9종은 작게, 퍼즐 소리를 끊지 않음(`SoundManager.play_battle`) |

| 수입 UP | 금화로 지갑 레벨을 올리면 한도와 초당 수입이 늘어남 (한도 200/320/480/700/1000, 초당 3/4/5/6.2/7.5, 비용 80/160/260/400) |
| 소환 | 자동이 금화를 내고 성 앞에 병사를 내보냄. 병사마다 대기시간(기사 2초 … 대포병 15초). 최대 14명 |

| 돌격/수비 | 전장 왼쪽 위 버튼. 수비면 병사가 성 앞(x 300)까지 물러나 버팀 |
| 자동 | **항상 켜짐**(2026-10-08부터 버튼 없음). 퍼즐만 해도 전투가 굴러가게: 금화가 모이는 대로 덱 병사를 소환(앞줄 먼저, 박쥐엔 원거리, 갑옷엔 창병·대포병, 몬스터가 성 가까이 오면 앞줄 우선, 상대 병사를 위해 금화를 모으기도 함), 몬스터가 2마리 이상이거나 보스면 대포 발사, 금화가 넉넉하면 수입 UP 2단계까지. 플레이어가 할 일은 퍼즐, 돌격/수비, 그리고 전투 밖의 뽑기·합성·덱 |
| 스테이지 | 24스테이지(4장×6)를 기사단 본부에서 골라 플레이. 장마다 새 적 → 시험 → 응용 → 보스 순서, 난이도는 톱니 모양(새 적은 쉽게, 보스가 벽). 몬스터 배율은 첫 클리어 보석만 쓴 플레이어의 예상 성급에 맞춤 → [LANE_STAGES.md](LANE_STAGES.md). 대웨이브가 3마리 이상이면 뿔피리와 경고 배너를 3초 먼저 |

## 12. 메타·리텐션

### 현재

- 로그인 없는 프로필: 자동 발급 ID + 닉네임 + 아바타 8종. 첫 실행 시 설정 팝업
- 실시간 랭킹: 전체 / 주간(ISO 주차) 탭, 내 순위 강조, 게임오버 시 자동 등록
- 설정: 사운드, 화면 흔들림, 블록 가이드라인, 진동 켜기/끄기
- 업적: 17개(누적 줄, 최대 콤보, 퍼펙트 클리어, 클래식 점수, 판 수, 신기록, 챌린지 참여일, 어드벤처 별). 달성 시 상단 알림, 설정의 "업적" 탭에서 진행 상황 확인
- 칭호: 2026-09-29 삭제. 보상 구조·획득 조건·표시 위치를 다시 기획한 뒤 새로 만듭니다(TASKS.md T-13)
- 어드벤처: 시작 보드·목표(점수/줄/보석)·이동 제한이 있는 스테이지 20개, 별 3단계와 순차 해금. 사양은 [ADVENTURE_MODE.md](ADVENTURE_MODE.md)
- 오늘의 챌린지: KST 날짜 시드로 모두에게 같은 블록 순서를 지급(적응형 생성 끔, 3개 중 큰 블록 최대 1개). 도전 횟수 무제한, 하루 최고 점수만 일간 랭킹에 반영. 전체·주간 기록과 분리
- 블록 스킨: 클래식·캔디·네온·보석 4종. 설정에서 고르면 보드와 트레이에 바로 반영

### 제안

v0.1에서 제안한 기능(오늘의 챌린지, 퍼펙트 클리어, 어드벤처 모드, 업적, 블록 스킨)은 구현했고, 칭호는 재기획을 위해 삭제했습니다. 다음 후보는 플레이 로그(13장)를 보고 정합니다.

수익화는 현재 사내 배포라 넣지 않습니다. 도입한다면 판 사이 광고와 보상형 부활만 고려하고, 판 도중 광고는 넣지 않습니다.
