# 서유기 테마 재편 — 16스테이지 (2026-10-10)

사용자 요청: "시나리오도 싹다 갈아 엎어, 주 내용은 서유기로. 서유기 요괴들과 에피소드를 맵·보스로. 총 16스테이지, 리소스 제작은 4개만."

기존 1~24스테이지(초원·숲·사막·설산·마왕성) 폐기. **서유기 삼장 일행이 장안에서 서천으로 가는 여정**으로 재편.

## 세계관

- 삼장(현장) 일행이 불경을 가지러 서천으로 간다. 길마다 요괴가 가로막는다.
- 서유기 "81난" 중 **가장 유명한 16 에피소드**를 뽑아 1 스테이지 = 1 요괴.
- 플레이어는 성(장안·수호 도장)을 지키고, 적 요새(요괴 소굴)를 파괴한다. 전투 시스템은 기존 블록 기사단 그대로.
- 플레이어 유닛(기사·궁수 등)은 **일단 그대로**. 테마 더 깊게 입히려면 다음 세션에 손오공·저팔계·사오정·삼장으로 교체 검토 (의견 받음).

## 보스 특기 메카닉 매핑

기존 1~3에 쓴 메카닉을 서유기 보스에 재배치:
- **분열** (왕슬라임 → 백골정 변신 각 단계마다 쫄몹)
- **광폭화** (고블린 두목 → 흑웅정)
- **공중·급강하** (밤의 눈 → 홍해아의 삼매진화는 화염으로 변형)

신규 메카닉 (1장만):
- **스턴 포효** (호선봉): 광역 짧은 스턴
- **다단 변신** (백골정): HP 지점마다 능력치·공격 패턴 교체 (3단)
- **광역 넉백** (사오정): 전장 전체 아군 뒤로

흑웅정 "돌진 넉백"은 기존 "charge" 메카닉 (1~3에선 미구현, 이번에 추가).

## 플레이어 유닛 (이번 세션 범위 밖)

지금은 기사·궁수·마법사 등 기존 블록 기사단 유닛 그대로. 서유기 테마가 재미있다는 피드백 받으면 다음 세션에 **삼장·손오공·저팔계·사오정·소룡마** 등으로 교체. 유닛 아트·이름만 바꾸면 기존 밸런스 유지.

## 쇼케이스·셀렉트

- 스테이지 수 24 → **16**. `lane_stage_select.gd` 수치만 고치면 레이아웃 그대로.
- 라벨 "스테이지 n/24" → "n/16", 별 "★x/72" → "x/48".

## 수치 (요새 체력·보상)

16스테이지로 줄어들고 챕터당 4개라 **더 가팔라야** 함:
- 1장: 요새 1200/1500/1800/2200
- 2장: 2800/3200/3700/4300
- 3장: 5000/5500/6200/7000
- 4장: 7800/8600/9500/11000 (16은 최종 보스)

보상은 번호 비례 (1 💎200, 2 💎240, ... 16 💎800).

구체 밸런스는 1장 리소스 구현 후 플레이로 검증.
