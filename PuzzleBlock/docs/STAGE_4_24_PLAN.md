# 4~24 스테이지 재설계 (2026-10-10)

사용자 요청: "18개 스테이지와 보스 몬스터 작업 남은거 싹다 해봐".

1~3 스테이지(`STAGE_1_3_PLAN.md`)에서 세운 패턴을 그대로 확장: **매 스테이지 고유 보스 + 고유 배경(또는 챕터 테마) + 고유 메카닉**.

## 챕터 구조 (4챕터 × 6스테이지 = 24)

| 챕터 | 테마 | 스테이지 |
|---|---|---|
| 1 초원·숲·동굴 | 밝은 초원 → 야영 숲 → 동굴 | 1~6 |
| 2 사막·오아시스 | 뜨거운 모래, 유적, 모래폭풍 | 7~12 |
| 3 설산·얼음 | 눈·얼음, 차가운 바람, 빙벽 | 13~18 |
| 4 지하 마왕성 | 어두운 성·납골당·용암 | 19~24 |

각 챕터 끝(6·12·18·24)은 **챕터 보스** — 더 크고 특기 2개, 전용 음악(가능하면).

## 메카닉 요약 (중복 피하고 변주)

- **분열** (1·19): 죽을 때 작은 몹 생성
- **광폭화** (2·23): 체력 비율별 공속·공격 증가
- **공중+급강하** (3·12·20·22): 근접 불가
- **소환** (4·11·18·21·24): 쫄몹 추가 (수량·종류·쿨 조절)
- **스텔스/투명** (8·20): 가끔 사라져 1~2초 못 때림
- **재생** (10): 체력 복구
- **돌진 넉백** (9): 전장 가로지르며 아군 밀어버림
- **독·둔화** (7·13·14·16): 원거리 상태이상
- **갑옷/방어막** (6·17): 피해 감소
- **보호막** (6): 일정 시간 무적
- **분신** (24): 복제체
- **분노 비율증가** (23)
- **관통 공격** (15)

## 수치 (요새 체력·보상)

기존 `LANE_STAGES.md` 수치를 베이스로 유지하되, 보스 메카닉이 추가되어 체감 난이도 올라가므로 요새 체력 **5~10% 하향**. 보상 보석은 기존 구조 유지 (스테이지 번호 × 상수).

구체 수치는 구현 에이전트가 `tools/sim_lane_progress.py`로 검증 후 미세 조정.
