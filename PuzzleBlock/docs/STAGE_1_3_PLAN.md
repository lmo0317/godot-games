# 1~3 스테이지 재설계 (2026-10-09)

사용자 피드백: "스테이지만 냅다 늘려 놓고 다음 깨도 크게 달라지는 것도 없고 난이도도 비슷해서 재미가 없다. 스테이지 하나하나 올라갈 때마다 재미있어야 한다. 일단 1~3만 기획부터 하고 보스·배경·쫄몹 다 그림 다시 그리고 다시 만들어라."

## 1. 왜 바꾸는가 (fun first)

현재 24스테이지는 데이터는 다르지만 **보기엔 같다** — 같은 평원 배경, 같은 쫄몹 묶음, 보스는 6판에 1마리뿐. 플레이어가 "진행하는 느낌"을 못 받음.

## 2. 핵심 원칙

1. **매 스테이지 보스 등장**: 요새 체력 50% 지점에서 그 스테이지 고유 보스 출현. 보스마다 **고유 특기**.
2. **보스 인트로**: 전투 시작 전 보스 샷 + 이름 + 특기 한 줄.
3. **고유 배경**: 스테이지마다 다른 배경 이미지.
4. **쫄몹 종류 묶기**: 1·2·3마다 쫄몹 조합 다르게.
5. **난이도 커브**: 1 쉽게 통과 → 2 겨우 → 3 벽(원거리 필수).

## 3. 스테이지 상세

### 스테이지 1 — "슬라임 들판"
- **배경**: 아침 초원, 밝은 녹색, 작은 꽃, 흰 구름.
- **쫄몹**: 슬라임 (떼로 몰림, 느리고 약함).
- **보스**: **왕슬라임** (스테이지 보스)
  - 바탕: 슬라임 ×1.8 크기, 보라색 몸체 + 왕관
  - 체력: ×8, 공격: ×2.5
  - **특기**: 죽을 때 작은 슬라임 2마리로 분열 (각 보통 슬라임 체력의 60%)
- **가르침**: 기본 — 기사로 막고 블록 지워 금화 모으기.
- **요새 체력**: 1200
- **웨이브**:
  - 시작: 슬라임 ×2
  - 25초: 슬라임 ×4
  - 50초: 슬라임 ×3 + 작은 슬라임 ×2
  - 요새 50% 지점: **왕슬라임** 등장 (인트로 번쩍)
- **보상**: 첫 클리어 보석 200, 별 30
- **의도된 결과**: 안 키운 덱도 깸, 재미 느끼게 함

### 스테이지 2 — "고블린 캠프"
- **배경**: 오후 숲 입구, 야영 텐트·화톳불·나무 울타리.
- **쫄몹**: 고블린 (빠름) + 슬라임 소수 (앞쪽).
- **보스**: **고블린 두목**
  - 바탕: 고블린 ×1.5, 이빨 자국 가죽 갑옷, 두 자루 손도끼
  - 체력: ×5, 공격: ×1.8
  - **특기**: HP 50% 이하 때 **광폭화** — 공속 ×1.5, 몸이 붉게 빛남
- **가르침**: 궁수의 원거리 활용. 고블린이 빠르게 몰려오니 궁수가 뒤에서 쏴야 함.
- **요새 체력**: 1500
- **웨이브**:
  - 시작: 고블린 ×2 + 슬라임
  - 20초: 고블린 ×3
  - 45초: 고블린 ×4
  - 요새 50% 지점: **고블린 두목** 등장
- **보상**: 첫 클리어 보석 220, 별 30
- **의도된 결과**: 기사만으론 밀림 → 궁수가 덱에 있어야 겨우 이김

### 스테이지 3 — "박쥐 동굴"
- **배경**: 어두운 동굴 입구, 보라/파랑 톤, 종유석, 희미한 빛.
- **쫄몹**: 박쥐 (날개, 근접 못 때림) + 고블린 (바닥).
- **보스**: **"밤의 눈" 거대 박쥐**
  - 바탕: 박쥐 ×2.2, 금안, 가죽 날개
  - 체력: ×6, 공격: ×2
  - **특기**: 하늘 날아 근접 못 맞힘. 가끔 땅으로 **급강하 공격** (큰 피해 + 넉백) 뒤 다시 상승.
- **가르침**: 날아다니는 적 → **원거리 병사 필수** (궁수·석궁병·마법사). 근접만으론 보스를 아예 못 때림.
- **요새 체력**: 1800
- **웨이브**:
  - 시작: 박쥐 ×2 + 고블린
  - 20초: 박쥐 ×3
  - 45초: 박쥐 ×2 + 고블린 ×2
  - 요새 50% 지점: **밤의 눈** 등장
- **보상**: 첫 클리어 보석 280, 별 30
- **의도된 결과**: **벽** — 원거리 병사 없으면 못 깸. 플레이어가 뽑기 돌려 궁수(또는 상위) 넣어야 함.

## 4. 보스 인트로 연출 (`scripts/lane_battle.gd`)

전투 시작 시 (덱 소환 전):
1. 화면 어두워짐 (modulate 0.3, 1.0초 fade in)
2. 가운데 **보스 샷** 크게 (아트의 큰 버전, 4배 스케일) 떨어지며 등장
3. 양피지 리본 아래로: 보스 이름 (큰 폰트 36px), 특기 한 줄 (22px)
4. 1.5초 유지 → [시작] 버튼 (또는 탭) → 인트로 사라지며 전투 시작

보스가 **실제 등장**할 때 (요새 50% 지점):
1. 화면 번쩍 + 흔들림 (0.2초)
2. 보스 샷이 전장 오른쪽에서 걸어들어옴 (큰 스케일)
3. 상단에 "BOSS: {이름}" 양피지 1.5초

## 6. 코드 변경

- `scripts/lane_stages.gd`: 1·2·3번 스테이지 데이터 교체. `stage_boss` 필드 추가(스테이지마다 보스 kind).
- `scripts/lane_battle.gd`: 보스 인트로 함수, 배경 스테이지별 교체.
- `scripts/lane_stage_select.gd`: 1~3 카드가 각자 그 스테이지 보스 아이콘을 보여주게.
- `scripts/lane_units.gd`: 왕슬라임 분열 로직은 몬스터 쪽이므로 별도 몬스터 데이터 파일 또는 이 파일에 추가.
- `tools/import_lane_art.py`: 새 아트 가져오기.

## 7. 밸런스 체크

사용자가 직접 1·2·3 플레이:
- 1: 안 키운 덱으로 쉽게 깸
- 2: 궁수 없으면 밀림, 궁수 넣으면 겨우 깸
- 3: 궁수 없으면 보스를 아예 못 때림 → 뽑기 유도

## 8. 범위 밖

- 4~24 스테이지는 그대로 둠. 이 패턴이 재미있다고 사용자가 확인하면 **같은 패턴으로** 4~24 확장.
- 스테이지 선택 화면은 이미 챕터 탭으로 리워크된 상태 유지.
