# 영웅 시스템 + 서유기 1장 (2026-10-10)

사용자 지시:
- 손오공·저팔계·사오정·삼장이 **영웅**, 1명씩 전투당 선택
- 기존 유닛(기사·궁수 등)은 **군대·부대** 느낌으로 영웅을 보조
- 영웅은 스토리 보상으로 얻음
- 전투 중 영웅 사망 → **영구 사망(스테이지 끝까지 부활 없음)**
- 손오공은 화과산 원숭이, 정화된 요괴 등 테마 유닛 — **첫 구현은 테마 유닛 제외, 영웅 1명 + 액티브 스킬만 넣음**(다음 세션에 테마 패시브 추가)

## 1. 영웅 (4명)

| 영웅 | 역할 | HP | 공격 | 간격 | 사거리 | 속도 | 액티브 스킬 | 쿨 |
|---|---|--:|--:|--:|--:|--:|---|--:|
| **삼장** | 서포터 | 300 | 6 | 1.5 | 80 | 24 | **염불 결계** — 아군 전원 4초간 받는 피해 ½ + 공격력 ×1.3 | 25s |
| **손오공** | 광역 공격 | 450 | 32 | 0.9 | 50 | 36 | **여의봉 광풍** — 전장 가로 전체 적에게 100 피해 + 큰 넉백 | 30s |
| **저팔계** | 탱커 | 600 | 20 | 1.3 | 44 | 24 | **쇄기 돌진** — 전방 180px 범위 150 피해 + 넉백 + 2초 스턴 | 28s |
| **사오정** | 균형 | 400 | 24 | 1.1 | 70 | 28 | **수룡 재생** — 자신 70% 회복 + 아군 전원 30% 회복 | 32s |

### 공통 규칙
- 전투 시작 시 **자동 소환** (금화 비용 없음). 성 바로 앞에 등장.
- **영구 사망**: HP 0 → 화면 어두워지며 "{이름}이 쓰러졌다!" 2초 배너 + 사망 효과. 부활 없음.
- **보유 유닛**과 **별도 슬롯**: 덱 4칸(군대)은 그대로, 영웅은 전투 시작 전 1 슬롯 고정.
- 스프라이트는 보통 유닛 ×2 크기(한눈에 "주인공" 느낌).
- 체력 바는 **상단 전용 바** (화면 좌측, 큰 초상화 + HP 숫자).

## 2. 영웅 획득 (스토리 보상)

| 영웅 | 획득 시점 | 서사 |
|---|---|---|
| 삼장 | **처음부터** (튜토리얼) | "삼장이 서천으로 떠난다…" |
| 손오공 | **스테이지 1 클리어** | 오지산에서 봉인 해제, "손오공이 합류했다!" |
| 저팔계 | **스테이지 2 클리어** | 백골산 뒤 고로장에서 만남, "저팔계가 합류했다!" |
| 사오정 | **스테이지 4 클리어** | 유사하에서 결투 후 동료, "사오정이 합류했다!" |

- 뽑기 없음. 모두 스토리 보상.
- 새 영웅 획득 시 **스토리 양피지 팝업** 1장 (얼굴 샷 + 짧은 대사).

## 3. 영웅 선택 화면 (전투 전)

쇼케이스 스테이지에서 [시작] 누르기 전에:
```
┌─ 영웅 선택 ────────────────────────┐
│                                    │
│  [삼장]  [손오공]  [저팔계]  [사오정]  │ ← 가진 영웅만 활성화
│   선택       잠금         잠금        │
│                                    │
│  큰 초상 + 이름 + 역할 + HP/공격/스킬│
│                                    │
│         [  이 영웅으로 출전!  ]     │
└──────────────────────────────────┘
```
- 가장 최근 선택한 영웅이 기본값.
- 아직 못 얻은 영웅은 잠금(흐림 + 자물쇠).

## 4. 전투 UI 추가

### 영웅 체력 바 (좌측 상단, 성 바 옆)
```
┌─ 손오공 ─┐
│ [초상화]  │
│ ████░░░ 320/450 │
└──────────┘
```
- 초상화 + 큰 HP 바 (돌 테두리). 체력 비율에 따라 녹→노→빨.
- 사망 시 초상 어두워지고 X 표시.

### 스킬 버튼 (화면 오른쪽 하단, 소환 버튼 옆)
- 큰 둥근 버튼 + 영웅 스킬 아이콘 + 쿨 숫자.
- 눌러서 즉시 발동(쿨 중이면 회색).
- 쿨 끝나면 반짝.

## 8. 밸런스

- 영웅은 **강력**: 보통 유닛 3~5배 체력/공격. 혼자서도 쫄몹 상대 가능하지만 보스엔 역부족 → 군대 소환 필수.
- 영웅 사망 시 **난이도 크게 상승** → 플레이어는 영웅 지키려 주의.
- 스킬 쿨은 25~32초로 넉넉 — 아껴 쓰기.
- 호선봉·백골정 보스 메카닉이 영웅을 노리면 긴장감 ↑.
