# 뽑기 조사 — 카드형 뽑기 게임은 어떻게 하나 (2026-10-09)

사용자 요청: "뽑기도 너무 구려, 다른 카드 형태의 뽑기 게임 참고해서 어떻게 해야 되나 찾아봐" (`game-designer` 조사).
지금 뽑기(2026-10-08 "뽑기 연출")는 제단이 충전되고 병사가 한 명씩 화면 가득 나온 뒤 요약을 보여 주는 방식.

## 참고 게임에서 찾은 것

| 게임 | 방식 | 배울 점 |
|---|---|---|
| **포켓몬 카드 게임 Pocket** | 팩 위쪽을 손가락으로 **쓸어서 찢음**, 찢는 소리·진동, 카드를 한 장씩 넘김. 레어가 나오면 "깨지는 소리 + 빛"이 꼭 나옴 | 내가 직접 여는 손맛. 개발진이 실제 팩을 여러 번 뜯어 보며 소리를 골랐을 만큼 **소리**가 핵심. 매일 여는 의식이라 짧고 기분 좋게 |
| **하스스톤** | 팩을 가운데로 **끌어다 놓으면 터지고**, 카드 5장이 **뒷면으로** 둥글게 놓임. 카드에 손을 대면(길게 누르면) **등급 색으로 빛남**(파랑 레어·보라 에픽·주황 전설). 직접 **눌러서 뒤집고**, 높은 등급일수록 뒤집을 때 폭발이 큼. 한 팩에 레어 이상 1장 보장 | 뒤집기 전에 "이 팩 좋다"를 먼저 알려 주고, **어떤 순서로 뒤집을지 내가 고름**(좋은 걸 아껴 두는 사람, 바로 뒤집는 사람). 여러 팩을 한 번에 열면 좋은 카드만 뒷면으로 보여 주고 나머지는 목록으로 |
| **페이트 그랜드 오더(FGO)** | 소환 빛이 보통 흰파랑, **금색이면 SR 이상 기대**, **무지개면 SSR 기대**, 빛 고리 3개면 서번트 확정 | 결과 전에 색으로 기대를 단계별로 올림 |
| **섀도우버스 Worlds Beyond** | 팩을 열기 전에 팩 둘레에 **금색·무지개 오라**, 카드를 뒤집을 때 위에서 금·무지개 빛이 내려옴 | 팩 단계와 카드 단계 두 번 예고 |
| **유희왕 마스터 듀얼** | 팩 8장 중 8번째 칸은 R 이상 보장, 10팩이면 마지막 팩 8번째는 SR 이상, 그래도 UR이 없으면 다음 10팩에 UR 보장 | 보장 규칙이 단계별로 있어 "다음엔 나온다"는 기대 |

공통점(뽑기 연출 연구 글): 색·움직임·소리가 함께 등급을 알리고 기대를 키움, 높은 등급일수록 효과를 키움, 반복해서 보면 지루하므로 넘기기·한 번에 보기가 필요.

## 지금 뽑기가 "구린" 이유

1. **내가 하는 게 없음.** 버튼 한 번이면 끝까지 저절로 흘러감. 찢기·끌기·뒤집기 같은 손맛이 없음.
2. **카드 게임처럼 안 보임.** 제단·포털은 추상적이고, 카드 뒷면·팩이 없어 "카드를 깐다"는 느낌이 없음.
3. **10회가 길고 단조로움.** 노멀 복제까지 한 명씩 화면 가득 보여 줌. 좋은 카드를 고르는 재미(하스스톤의 뒷면 빛) 없음.
4. **결과가 작음.** 마지막 요약이 작은 카드 격자라 무엇을 얻었는지 한눈에 안 들어옴.

## 제안: "카드 팩" 뽑기

1. **팩**: 10회 = 카드 10장 팩, 1회 = 카드 1장. 팩 그림(도트)이 가운데. 레어 이상이 들었으면 팩 둘레에 그 색 오라(유니크 보라, 레전더리 금), 가끔 오라가 한 단계 위로 바뀜.
2. **열기**: 팩 윗부분을 **손가락으로 쓸면 찢어짐**(찢는 소리·진동). 그냥 눌러도 열림.
3. **펼치기**: 카드 10장이 **뒷면으로** 날아와 5×2로 놓임. **뒷면이 등급 색으로 빛남**(레어 파랑, 유니크 보라 + 흔들림, 레전더리 금 + 맥동).
4. **뒤집기**: 카드를 **눌러서 한 장씩** 뒤집음(순서는 내 마음). 노멀은 그 자리에서 휙, 레어는 파란 번쩍, **유니크·레전더리는 뒤집는 순간 화면 가득 등장 연출**(지금의 큰 공개를 여기서만). [모두 뒤집기] 버튼으로 남은 걸 한 번에.
5. **결과**: 다 뒤집힌 10장이 그대로 결과 화면. 카드마다 NEW! / "+1 · 합성까지 1/2", 합성할 수 있는 카드는 반짝임. [합성하러 가기] [다시 10회].
6. (선택) **보장 표시**: "유니크 이상까지 앞으로 N회" — 유희왕·FGO식 단계 보장. 확률이 바뀌므로 따로 확인 필요.

필요한 그림(아트 디렉터): 카드 뒷면 1종(등급 빛은 코드로 색 입힘), 카드 팩 1종, 찢어지는 팩 윗부분 1종 — Codex 한 장 시트. 효과음: 팩 찢기, 카드 날아옴, 뒤집기(등급별), 모두 뒤집기.
