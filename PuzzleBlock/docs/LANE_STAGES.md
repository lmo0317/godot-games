# 블록 기사단 스테이지 기획서 (24스테이지)

블록 기사단을 스테이지별로 나눠, 기사단 본부(스테이지 선택)에서 골라 들어가고 적 요새를 부수면 다음 스테이지가 열립니다. 12스테이지(2026-10-07 오전)에서 **24스테이지(4장 × 6)**로 늘리고, 스테이지마다 배울 것 하나를 정해 더 촘촘하게 짰습니다(같은 날 사용자 요청: "24개 정도로 확장해서 더 타이트하게").

병사·뽑기·덱은 [LANE_UNITS.md](LANE_UNITS.md), 전투 규칙은 [GAME_DESIGN.md](GAME_DESIGN.md) 11-1장.

## 1. 흐름

```
홈 [블록 기사단] → 기사단 본부 (24칸, 보석, [병사 뽑기] [덱 편성] [홈으로])
  └ 스테이지 → 전투 (덱 4칸 소환, 금화·병사·퍼즐판 새로 시작)
       ├ 적 요새 파괴 → 클리어: 별 1~3, 보석, 다음 스테이지 열림
       └ 성 붕괴 / 퍼즐판 막힘 → 실패
  → 결과 창 [본부로 돌아가기] → 본부에서 뽑기·덱 정비 → 다음 스테이지
```

- 별: 남은 성 체력 80% 이상 ★★★, 50% 이상 ★★, 그 밖 ★.
- 전투 중 집 버튼·뒤로 가기는 본부로.

## 2. 설계 원칙

1. **스테이지마다 배울 것 하나.** 새 몬스터, 새 상황(빠른 적, 원거리 적, 회복하는 적, 거대한 적, 하늘 떼)을 하나씩 꺼내고, 그 다음 스테이지에서 섞습니다.
2. **필요한 병사는 뽑기로 미리 모으게.** 클리어 보석으로 스테이지마다 1~3번 뽑을 수 있어, 박쥐(5) 전에 원거리 병사, 갑옷(11) 전에 창병·대포병을 모을 시간이 있습니다. (처음엔 첫 클리어 보상으로 병사를 줬으나 사용자 요청으로 보석만 줌)
3. **6스테이지마다 보스**(6·12·18·24). 장의 마지막. 요새 체력이 절반일 때 포효·충격파로 등장.
4. **한 판 2~4분.** 요새 체력과 반복 웨이브(마지막 웨이브가 40초마다 다시 옴)로 길이를 맞춤.
5. **어려움 곡선은 완만하게 한 칸씩**: 배율 1.0 → 1.55, 요새 1000 → 3500, 몬스터 간격 11초 → 7초. 장이 바뀔 때 시작 금화·수입 단계가 한 단계 올라감(시작 금화 60 + 15×(스테이지−1), 수입 단계 = 장 번호).
6. **장마다 하늘 색**: 1장 초원(낮) / 2장 숲(해질녘) / 3장 묘지(밤) / 4장 마왕성(붉은 하늘).

## 5. 밸런스 확인

덱 [기사·궁수·마법사·창병] 레벨 1, 자동 모드, 6초마다 줄 1~2개 지우는 가상 플레이어로 스테이지마다 돌려 봅니다. 목표:

- 1장: 거의 항상 클리어
- 2장: 대부분 클리어, 성이 깎임
- 3장: 반반 — 뽑기로 얻은 병사·레벨이 있으면 쉬워짐
- 4장: 기본 덱으로는 어려움 — 덱을 키워야 함
